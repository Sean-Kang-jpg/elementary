# 1학년 오후 시간대 검토 지시서 (상위 모델 재검토, 2026-10-24)

입력은 학교마다 두 파일이다.

- 원문: `etl/runtime/llm_extraction/inputs_v3/<school_id>.txt`. 학교알리미 15-라 첨부 전체이고 줄마다 `L번호:`가 있다. 표의 병합 셀은 덮는 모든 줄에 반복되어 있다.
- 시간대 목록: `etl/runtime/llm_extraction/opus_slot_audit/<school_id>.json`. 다른 모델이 원문에서 뽑은 **1학년이 쓸 수 있는 오후 시간대**다. 각 항목은 `[번호, 종류, 요일, 시작, 종료, 이 시간대의 강좌(일부)]`이다.

이 두 파일 외에는 읽지 않는다.

## 시간대란

부모가 1학년 시간표를 짤 때 쓰는 **요일별 시간 창**이다. 2026학년도 학기 중 오후에 열리는 다음 두 가지만 해당한다.

- **맞춤형**: 늘봄 초1·2 맞춤형 프로그램(무료). 돌봄교실 안에서 운영하는 맞춤형도 포함한다. 돌봄교실의 간식·휴식·자유놀이·짧은 일과 활동은 아니다.
- **저학년 방과후**: 대상 학년이 1학년을 포함하고 3학년 이하에서 끝나는 반(예: 1~2학년, 1~3학년). "1~6학년"처럼 고학년까지 열린 반과 대상 학년이 적혀 있지 않은 반은 **제외**한다.

다음은 시간대가 아니다: 아침·토요·방학 강좌, 특수학급 전용 반, 2025학년도 이전 자료, 여러 반을 합친 전체 운영 구간("13:00~17:20, 4개 반"처럼 반별 시각이 아닌 것).

같은 요일·시작·종료면 강좌가 여러 개여도 시간대 하나다.

## 할 일

먼저 원문을 처음부터 끝까지 읽고, 위 정의대로 이 학교의 시간대를 스스로 정리한다. 그다음 목록과 비교한다.

1. **목록의 각 시간대**를 판정한다: `ok`, 또는 `wrong`과 이유. 틀린 이유는 `요일`(그 요일에 없음), `시각`(시작·종료가 원문과 다름), `대상아님`(위 정의상 시간대가 아님) 중 하나이고, 근거 L번호를 붙인다.
2. **빠진 시간대**를 적는다: 원문상 시간대인데 목록에 없는 것.
3. **원문만으로 정할 수 없는 것**은 따로 적는다(예: 시각이 교시 조건으로만 있음, 표가 깨져 요일을 알 수 없음).

엄격하게 보되, 원문 근거가 있는 것만 오류로 적는다.

## 출력

지정된 경로에 JSON 객체 하나를 쓴다:

```json
{
  "school_id": "B000000000",
  "my_slot_count": 14,
  "verdicts": [[1, "ok", null], [2, "wrong", "시각: L120은 14:20 종료"]],
  "missing": [["맞춤형", "목", "13:50", "15:10", "L88"]],
  "undeterminable": ["맞춤형 요일표가 깨져 요일 대응 불명 (L60-64)"],
  "note": "한 줄, 없으면 null"
}
```

`my_slot_count`는 내가 원문에서 정리한 시간대 수다. 담당자·강사 이름, 전화번호는 옮기지 않는다. 다른 파일은 만들거나 고치지 않는다.
