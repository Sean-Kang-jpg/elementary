# E05 v3 방과후·맞춤형 통합 추출 지시서

입력: `etl/runtime/llm_extraction/inputs_v3/<school_id>.txt`. 학교알리미 15-라(방과후·돌봄 운영계획) 첨부 **전체**이고, 줄마다 `L번호:`가 붙어 있다. 표는 `칸 | 칸 |` 형태이며 **병합 셀은 그 셀이 덮는 모든 줄에 반복**되어 있다. 그래서 각 줄을 그대로 읽으면 강좌명·요일이 빠지지 않는다. **이 파일 외에는 아무것도 읽지 않는다.**

목표: 2026학년도 **방과후(유료)와 맞춤형(늘봄 초1·2 맞춤형, 무료)의 모든 강좌·반**. 요일, 시간, 대상 학년, 그 학년이 어디에 적혀 있었는지까지 뽑는다. 근거 문장은 옮기지 않고 **줄 번호만** 적는다.

원칙: **판단은 줄이고 기록은 남긴다.** 1학년이 못 듣는 반, 아침·토요 강좌도 지우지 않고 행으로 남긴다. 어느 것을 보여 줄지는 코드가 `기간`과 `1학년판정`으로 정한다.

학교마다 JSON 객체 하나:

```json
{
  "school_id": "B000000000",
  "rows": [
    ["방과후", "생명&실험과학", null, "A", "1~2", "row", "목", "13:10", "14:30", "true", "학기", "2026 1분기", null, 81],
    ["맞춤형", "놀이체육", null, null, "1~2학년", "table", "월", "12:40", "14:40", "true", "학기", "2026 연간", "돌봄내", 140]
  ],
  "note": "판단이 필요했던 점 한 줄, 없으면 null"
}
```

각 행은 `[종류, 강좌명, 과정, 반, 대상학년원문, 학년출처, 요일, 시작, 종료, 1학년판정, 기간, 학기표기, 운영장소, 줄번호]` 순서다(14칸, 2026-10-21 운영장소 추가).

| 칸 | 값 |
| --- | --- |
| 종류 | `방과후` 또는 `맞춤형`. 맞춤형은 "맞춤형", "늘봄 맞춤형", "초1 맞춤형" 표·단원에 있는 프로그램이고, **돌봄교실 안에서 운영하는 맞춤형("돌봄 내 맞춤형", 돌봄 n반의 요일별 프로그램)도 맞춤형이다.** 돌봄교실의 간식·휴식·자유놀이 같은 일과는 어느 쪽도 아니므로 넣지 않는다 |
| 강좌명 | 원문 그대로. 맞춤형은 **요일별 실제 프로그램명**(놀이체육, 음악놀이 등)을 쓴다. "맞춤형교실", "프로그램A"처럼 총칭만 있으면 그 이름을 쓰고 `note`에 적는다 |
| 과정 | 학부모가 **수준·내용을 골라야 하는** 과정명(Basic, 컴기초 등). 시간만 다른 반이면 `null` |
| 반 | 원문 반 표기(A, B, 1반, 1부), 없으면 `null` |
| 대상학년원문 | 그 반에 적용되는 학년 원문, 없으면 `null` |
| 학년출처 | `row`(그 행 또는 같은 표의 열·행 머리글), `table`(표 바로 위 제목·단원 제목, 예: "가. 1~2학년 맞춤형 프로그램"), `school`(문서 전체에 한 번 나오는 대상 문장, 예: "초1~6학년 대상 방과후교실"), 없으면 `null` |
| 요일 | 월화수목금 중 해당 글자를 붙여 씀(예: `"화목"`). 모르면 `null`. "월~금 중 주1회"처럼 범위만 있으면 `null` |
| 시작·종료 | `HH:MM`. 원문에 없으면 `null`. 오후 12시간제(1:30)는 13:30으로 쓴다. 시각을 만들지 않는다 |
| 1학년판정 | 대상학년원문에 1학년이 들어 있으면 `"true"`("1~6", "1-2학년", "저학년", "1·2학년"). 1학년이 없으면(`3~6`, `2학년`) `"false"`. 원문이 없으면 `"unknown"`. 학년출처가 `school`이어도 판정은 같은 기준으로 한다 |
| 기간 | `학기`(학기 중 오후), `아침`(정규 수업 전), `토요`, `방학`. 방학 시간표만 있는 반은 `방학` |
| 학기표기 | 그 표가 속한 기간 원문(예: `2026 1분기`, `2026 1기`, `2026 연간`). 모르면 `null` |
| 운영장소 | 돌봄교실 안에서 운영하면 `돌봄내`("돌봄 내 맞춤형", 반 이름이 돌봄 1반·돌봄2실 등), 아니면 `null`. 돌봄을 다니는 아이만 참여할 수 있다는 뜻이라 화면이 따로 알린다 |
| 줄번호 | 그 반의 시각이나 학년이 적힌 줄의 L번호(정수) |

## 규칙

- **2025학년도 이전 문서·표는 출력하지 않는다.** 정산서, 지난해 계획은 `note`에 "2025 자료 제외"로만 남긴다.
- **같은 표가 본안과 수정안으로 두 번 있으면 수정안만 쓴다.** 분기·기수마다 다른 표는 모두 쓰고 `학기표기`로 구분한다.
- **학기 중 시간과 방학 중 시간이 한 행에 같이 있으면**(예: `학기중 13:00-14:20 | 방학중 9:00-10:20`) 학기 중 시간으로 `기간=학기` 행 하나만 만든다.
- **요일별 맞춤형:** "요일 | 월 | 화 …" 아래 "프로그램명 | 놀이체육 | 음악놀이 …"처럼 나뉘어 있으면 요일마다 한 행을 만든다. 운영 시간 문장(`월목 12:40~14:40`)이 따로 있으면 그 요일에 적용한다. 프로그램명은 있지만 요일 대응이 정말 없으면 요일 `null`로 남긴다. 번호 순서를 월~금으로 추정하지 않는다.
- **학년별 표가 따로 있으면**(1학년 표, 2학년 표) 각 표의 행을 모두 쓰고, 학년은 그 표의 학년으로 적는다.
- **특수학급 전용 반은 넣지 않는다.** "특수학급", "특수교육대상 학생" 전용 강좌(특수체육 등)는 `note`에만 적는다.
- **여러 반을 합친 운영 시간대는 반의 시각이 아니다.** "원어민영어교실 | 13:00~17:20 | 4개 반"처럼 반별 시각 없이 전체 운영 구간만 있으면 시작·종료를 `null`로 두고 `note`에 "운영 시간대만 있음"을 적는다. 반별 시간표가 따로 있으면 그것을 쓴다.
- **기수별 표:** 1기·3기처럼 기수마다 같은 반이 반복되어도 기수마다 행을 남긴다. 같은 반을 합치는 일은 적재 코드가 한다.
- 담당자·강사 이름, 전화번호, 업체명은 옮기지 않는다.
- 강좌가 하나도 없으면 `rows: []`로 두고 `note`에 이유를 쓴다.

출력: 지정된 파일 경로에 JSON 배열 하나(학교마다 객체 하나)를 쓴다. 다른 파일은 만들거나 고치지 않는다.
