# E05 맞춤형 프로그램명 재추출 지시서

입력: `etl/runtime/llm_extraction/inputs_custom/<school_id>.txt`. `[AFTERSCHOOL]` 아래 각 줄에 `L번호:`가 붙어 있다. 내용은 학교알리미 15-라 첨부에서 '맞춤형'이 나온 줄과 앞뒤 12줄이다. **이 파일 외에는 아무것도 읽지 않는다.**

배경: 첫 추출에서 이 학교들의 맞춤형은 "맞춤형교실", "맞춤형 프로그램"처럼 이름 하나로 묶였다. 그런데 운영계획에는 요일별 프로그램명이 따로 표로 있는 경우가 많다(예: `프로그램명 | 놀이체육 | 음악놀이 | 블럭놀이 ...`가 `요일 | 월 | 화 | 수 ...` 아래에 있음). 운영 시간은 다른 줄에 있다(예: `월목 12:40~14:40`, `화수금 13:40~15:40`).

목표: **맞춤형(늘봄 초1·2 맞춤형, 무료) 프로그램만**, 요일마다 한 행. 방과후(유료) 강좌는 넣지 않는다.

학교마다 JSON 객체 하나:

```json
{
  "school_id": "B000000000",
  "rows": [
    ["놀이체육", "월", "12:40", "14:40", "1~2학년", 140]
  ],
  "note": "판단이 필요했던 점 한 줄, 없으면 null"
}
```

각 행은 `[프로그램명, 요일, 시작, 종료, 대상학년원문, 줄번호]`.

| 칸 | 값 |
| --- | --- |
| 프로그램명 | 원문 프로그램명 그대로. 이름이 정말 없으면 이 행을 만들지 않는다 |
| 요일 | 월화수목금 중 한 글자. 같은 프로그램이 여러 요일이면 요일마다 행을 나눈다 |
| 시작·종료 | `HH:MM`. 요일별 운영 시간 문장(`월목 12:40~14:40`)을 그 요일에 적용한다. 원문에 없으면 `null`. 오후 12시간제(1:30)는 13:30 |
| 대상학년원문 | 맞춤형 대상 학년 원문(예: `1~2학년`, `1학년`), 없으면 `null` |
| 줄번호 | 프로그램명이 적힌 줄의 L번호(정수) |

## 규칙

- 학기 중 프로그램만. 방학 중 운영(오전 시간대 등)은 빼고, 방학 시간을 학기 시간으로 쓰지 않는다.
- 학년별로 프로그램이 다르면(1학년 / 2학년 표) 1학년 표를 쓰고 대상학년원문에 그 학년을 적는다. 1학년 표가 없고 공통이면 공통 표를 쓴다.
- 분기·기수별 표가 여러 개면 가장 이른 학기(1분기·1학기·3월) 표만 쓴다. 본안과 수정안이 있으면 수정안.
- 시각을 만들지 않는다. 담당자·강사 이름, 전화번호는 옮기지 않는다.
- 요일별 프로그램명이 없고 "맞춤형교실" 같은 총칭만 있으면 `rows: []`, `note`에 "요일별 프로그램명 없음".

출력: 배치마다 JSON 배열 하나를 지정된 파일 경로에 쓴다. 다른 파일은 만들거나 고치지 않는다.
