# E05 방과후·맞춤형 추출 지시서 (1학년 기준, 축소 출력)

입력: `etl/runtime/llm_extraction/inputs_afterschool/<school_id>.txt`. `[AFTERSCHOOL]` 아래 각 줄에는 `L번호:`가 붙어 있다. 내용은 학교알리미 15-라(방과후·돌봄 운영계획) 첨부에서 시간이 적힌 강좌표 줄과 앞뒤 두 줄이다. **이 파일 외에는 아무것도 읽지 않는다.**

목표: **1학년이 들을 수 있는 학기 중 방과후·맞춤형 강좌**와 요일·시간. 근거 문장은 옮기지 않고 **줄 번호만** 적는다.

학교마다 JSON 객체 하나:

```json
{
  "school_id": "B000000000",
  "rows": [
    ["방과후", "영어", "Basic", "A", "1-2학년", "월수금", "13:00", "13:40", "true", 79]
  ],
  "term": "1분기 | 1학기 | 연간 | null",
  "note": "판단이 필요했던 점 한 줄, 없으면 null"
}
```

`rows`의 각 행은 `[종류, 강좌명, 과정, 반, 대상학년원문, 요일, 시작, 종료, 1학년판정, 줄번호]` 순서다.

| 칸 | 값 |
| --- | --- |
| 종류 | `방과후` 또는 `맞춤형`(늘봄 초1 맞춤형, 무료) |
| 강좌명 | 원문 강좌명 그대로 |
| 과정 | 학부모가 **수준·내용을 골라야 하는** 과정명(예: Basic, Starter, 컴기초). 같은 강좌를 시간만 나눈 반이면 `null` |
| 반 | 원문 반 표기(A, B, 1반 등), 없으면 `null` |
| 대상학년원문 | 그 행 또는 직접 연결된 머리글의 학년 원문, 없으면 `null` |
| 요일 | 월화수목금 중 해당 글자를 붙여 씀(예: `"화목"`), 모르면 `null` |
| 시작·종료 | `HH:MM`. 원문에 없으면 `null`. 오후 12시간제(1:30)는 13:30으로 쓴다 |
| 1학년판정 | `"true"` 또는 `"unknown"` |
| 줄번호 | 시간이나 학년이 적힌 줄의 L번호(정수). 여러 줄이면 대표 줄 하나 |

## 규칙

- **1학년 판정**
  - 그 행이나 직접 연결된 머리글에 1학년이 들어 있으면 `"true"`이다. 예: "1-2학년", "1~6학년", "저학년".
  - 학년이 없거나 연결이 불분명하면 `"unknown"`이다.
  - 학교 전체 대상 문장("1~6학년 희망 학생")은 근거로 쓰지 않는다.
  - **1학년이 못 듣는 행("2-6학년", "3~6학년")은 출력하지 않는다.**
- **분반:** 병합 셀이라 강좌명이 빠진 행은 바로 위 강좌의 다른 반이다. 강좌명과 과정은 위 행의 것을 쓴다.
- **빼는 것:** 돌봄교실 내부 일과, 특수학급 전용, 방학 중 강좌, 수강료만 있는 표.
- **여러 분기·표:** 같은 강좌가 여러 분기에 반복되면 가장 이른 학기 중 분기를 쓰고 `term`에 적는다. 변경안이 있으면 변경된 값을 쓴다.
- 시각을 만들지 않는다. 담당자 이름, 전화번호는 옮기지 않는다.
- 강좌가 없으면 `rows: []`로 두고 `note`에 이유를 쓴다.
