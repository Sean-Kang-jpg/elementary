# P1 인수 메모 — 경기 방과후 강좌 (어디초 2.0 파일럿)

받는 사람: 방과후 추출기(v3)·적재기 담당 팀원. 2026-10-20.

## 부탁하는 일

운영 파일럿 생활권(분당·판교, 위례)의 경기 학교 **44곳**에 방과후·맞춤형 강좌가 운영 DB에 없다.
서울 536+25곳에 쓴 경로 그대로 15-라(방과후학교 운영 계획) → v3 추출 → 적재로 채워 주세요.

- 대상: `docs/research/pivot/p1_afterschool_operating_20261020.json` — 분당구 38곳, 위례 성남 수정구 4곳·하남 2곳.
- 기한: **11월 첫 주.** 학원 전화·학부모 인터뷰가 그때 시작되고, 결과 화면이 이 데이터를 쓴다.
- 이어서(급하지 않음): 3단계 수지·동안·광명 83곳. 목록은 `pilot_manifest_20261020.json`에서 `stage == 3`이고 `missing`에 `afterschool`이 있는 학교.

## 지켜 주실 것

- 결과는 `etl/runtime/llm_extraction/outputs_afterschool/pivot_gyeonggi/`에 둔다. 파일럿 브랜치는 이 폴더를 읽기만 한다.
- 먼저 3~5곳으로 시험해 경기 문서가 v3로 잘 읽히는지 본다. 서울과 형식이 다를 수 있다.
- 운영 적재는 사용자 확인 뒤. 적재기의 '기존 학교 빠지면 중단' 안전장치(gap37 작업)가 커밋된 상태에서 돌린다 — 지금 그 커밋이 대기 중이다.
- 적재 명령에는 기존 서울 출력 전부(`seoul`, `seoul_retry`, `seoul_noas`, `seoul_gap37_reviewed` 등)를 함께 넣는다. 전체 교체 적재라 빠진 출력의 학교는 지워질 뻔하고, 안전장치가 그때 멈춘다.

## 파일럿 브랜치가 하는 일

- 44곳 결과 중 운영 파일럿 학교를 원문과 대조 검수 → `docs/research/pivot/p1_review_*.json`으로 돌려 드림.
- 같은 기간 하교 예상 빈 17곳(P2)은 파일럿 브랜치가 맡는다. 방과후 테이블은 건드리지 않는다.
