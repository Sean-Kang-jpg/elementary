## 측정으로 알아낸 것

`unassigned_point_nohit`는 "대표점이 어느 폴리곤에도 안 들어갔다"는 사실만 말하고 원인은 말하지 않습니다.
학구도 폴리곤 7,140개와 직접 대조해 각 점에서 최근접 경계까지의 거리를 쟀습니다(EPSG:5186, 미터).

**폴리곤 안에 있는데 미배정된 점은 0건입니다.** 공간조인 자체는 정상이고, 20개 점이 실제로 모든 학구 밖에 있습니다.
다만 얼마나 밖인지가 갈립니다 — 최소 17m, 중앙값 72m, 최대 393m.

| 분류 | 기준 | 건수 |
|---|---|---|
| 좌표 오차 수준 | 경계까지 30m 이하 | 6 |
| 학구 사이 틈 | 30m 초과이나 300m 내에 학구 2개 이상 | 11 |
| 학구 커버리지 밖 | 30m 초과이고 주변 학구 1개 이하 | 3 |

경계까지 30m는 건물 한 채 폭도 되지 않습니다. 대표점이 건물이 아니라 지번 중심에 찍혀
도로나 필지 경계 너머로 넘어간 경우로 보는 것이 자연스럽습니다.

### 한 지점에 몰린 것들

부산진구 전포초 일대에 **4건**(은하수빌 A·B동, 세원하우스, 청안에버빌)이 47~76m로 붙어 있습니다.
단지 4개의 개별 문제가 아니라 그 지점 폴리곤 하나의 결손입니다. 상주 함창 1·2단지도 같은 단지입니다.
따라서 19건은 지점으로 세면 **15곳**입니다.

세대 규모가 큰 두 곳 — 여수 힐스테이트죽림젠트리스(989세대, 21m)와 전주 에코시티 데시앙 네스트 3블럭(830세대, 96m) —
도 모두 경계 문제이지 데이터 공백이 아닙니다. 두 단지만으로 1,819세대가 지도에서 빠져 있습니다.

## 다시 측정하려면

```bash
python etl/measure_unassigned_points.py --all
```

판정은 `etl/review_verdicts.csv`에 `region,case_type,subject,verdict,note`로 기록되고,
`etl/collect_review_cases.py`가 검수표를 만들 때 다시 붙입니다. 미판정 건은 항상 목록 맨 위에 옵니다.
