# 학원·교육시설 데이터 월간 자동 갱신 계획

작성 2026-10-05. 상태: **P0~P3 완료(2026-10-06, 첫 운영 적용 run `34ebb91f`). 남은 것: SQL 25 적용, P4 Actions 수동 실행, P5 11월 정기 실행 확인**.

## 0. 요약

지금 학원 레이어는 9월 말에 손으로 한 번 만든 뒤 멈춰 있다. 매월 ETL은 직업기술 제외 가드
(`apply_academy_realm_exclusion.py`)만 돌고, 새로 생기거나 문 닫은 학원은 반영하지 않는다.

이 계획은 학원 갱신을 월간 ETL의 세 번째 그룹(`academy`)으로 넣는다. 매월 다음 일을 한다.

1. NEIS 학원 전수와 체육도장 인허가를 새로 받는다
2. 새 주소만 지오코딩한다. 캐시는 비공개 Storage에 두고 이어 쓴다
3. 지역별로 근접도를 다시 계산한다
4. 지역 단위 **전체 교체**로 올린다. 지금 업로더는 추가만 하고 지우지 않는다

착수에는 사용자 결정 3건(1절)이 필요하다. 그 뒤 코드 작업 2~3세션, 검증 1세션이면 11월 정기
실행에 맞출 수 있다. 결정이 늦어지면 12월 정기 실행이 첫 적용이다.

## 1-1. 구현하면서 바꾼 것 (2026-10-06)

구현은 `etl/run_academy_refresh.py` 하나에 모았다. 아래 3-1의 A1~A6은 이 파일의 단계가 됐고,
기존 스크립트는 고치지 않고 그대로 호출한다. 계획과 달라진 점은 셋이다.

- **D3는 전체 중단으로 구현했다.** 한 지역이라도 15% 넘게 줄면 그 지역만 빼는 대신 **이번 달 학원
  갱신 전체를 올리지 않는다.** 주소 하나가 두 지역 단지에 함께 걸려 있어서, 일부 지역만 바꾸면 요약과
  주소 행이 서로 다른 달의 데이터가 된다. 결과는 같다: 지난달 데이터가 그대로 남고 실행은 실패로 기록된다.
- **체육도장 원천이 15% 넘게 줄어도 중단한다.** 병합을 건너뛰는 안은 쓰지 않았다. 건너뛰면 체육도장
  주소 1만 5천여 곳이 빠져 어차피 D3에 걸린다.
- **건물 동 좌표 2종과 지오코딩 캐시는 inputs 번들이 아니라 Storage `etl-source-snapshots/academy-refresh/`에
  둔다(A9 대신).** 번들은 월간 ETL 전체가 함께 쓰는 것이라, 학원 때문에 버전을 올리다 실수하면 아파트·학교
  갱신까지 멈춘다. 처음 한 번 `--seed-storage`로 이 PC의 파일을 올려야 러너가 시작할 수 있다.

- **지오코딩은 GitHub 러너가 아니라 이 PC의 Windows 작업이 한다(2026-10-06).** Actions 리허설에서 VWorld 재시도가
  전부 접속 오류였고, VWorld가 해외 IP를 막는다는 사례가 여럿 보고돼 있다. 카카오 Local API는 결과 저장을
  금지해(운영팀 답변 2026-08) 대안이 못 된다. 매월 1일 21:00 `Elementary Local Monthly ETL` 작업이 NEIS를
  수집해 새 주소만 변환하고 캐시를 Storage에 올린다. 러너는 지오코딩을 건너뛰고 그 캐시를 쓴다.
  이 PC가 꺼져 있으면 켜질 때 실행되고, 그사이 생긴 주소는 한 달 늦게 나온다.

### 3-2. 바꾸지 않는 것

- 공개 계약은 그대로다. 테이블 3개와 RPC 3개의 열·권한을 바꾸지 않는다. 프런트엔드 변경도 없다.
  예외는 학원 기준일 표시로, 원하면 A8 뒤에 따로 붙인다.
- `address_id`는 정규화한 도로명주소의 SHA-256 앞 24자다. 학원이 같은 주소에 남아 있으면 id가 그대로라
  링크·캐시가 깨지지 않는다.

  따른다.

## 7. 기관 단위 키 (2026-10-06 실측)

지금 파이프라인은 기관을 식별하지 않는다. 마커는 `address_id`(주소) 단위이고, 마커 빌더는 기관을
(이름, 유형, 분야)로 묶어 원천의 기관 키를 버린다. 그래서 개원·폐원·이름 변경을 구분할 수 없고,
같은 주소에 이름이 같은 두 기관은 하나로 합쳐진다. 학원 단위 기능(월간 변경 감지, 입학 준비·투표
기능의 아이템 사전, 기관별 영구 주소)은 모두 기관 키가 있어야 할 수 있다. 그리고 변경 이력은
키를 보관하기 시작한 달부터만 쌓인다.

### 7-1. 키는 둘 다 복합키다

| 원천 | 키 | 단독 값 | 복합키 |
|---|---|---|---|

### 7-2. 학원 키의 한 달 안정성 (수도권 9/8 → 10/6, 71,690곳)
