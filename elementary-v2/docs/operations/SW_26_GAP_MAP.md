# SW-26 · 빈 시간 지도 검증 기록

## 적용

- 해당 학교의 공개 하교·강좌 자료와 기존 초안을 같은 격자에서 표시한다. 후보는 점선이고, 후보 일정은 엔진의 빈 시간을 차감하지 않는다.
- 보호자 귀가 전까지의 공백은 기존 `coverageUntil` 및 커버리지 엔진과 같은 구간을 쓴다. 20분 미만은 빗금으로 표시하며, 나머지는 누른 위치를 10분 단위로 맞추고 최대 60분을 제안한다.
- 기존 TS 저장 형식과 완료 기록을 유지한다. 돌봄 제안에 미응답이면 `null`로 남는다. 개별 일정 저장은 완료로 세지 않으며, 기존 하교 즉시 분기와 명시적 ‘다 됐어요’ 기준을 유지한다.
- 같은 시트에서 학교 강좌 선택과 이름·유형·시각·반복 요일을 편집한다. 학교 확인 이유는 수정 시트에 들어 있다. 학교/방과후 출처와 다른 요일의 기존 수정은 보존한다.
- 승인된 A안 문구는 Vite와 빌드의 `dist/timetable/index.html` 및 SPA에서 확인한다.

모바일 에뮬레이션에서 텍스트 입력 포커스와 레이블, 네이티브 모달 및 접근성 트리를 확인했다. Orca에 연결된 에뮬레이터·실기기가 없고 이 호스트에서 Xcode `simctl`을 사용할 수 없었다. 가상 키보드의 실제 높이 변화와 iOS VoiceOver/Android TalkBack 음성 안내는 미검증이다.
