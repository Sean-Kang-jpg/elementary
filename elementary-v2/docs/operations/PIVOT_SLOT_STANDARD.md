# 파일럿 방과후 수집 기준 — 시간대 우선 (2026-10-24 사용자 결정)

받는 사람: 경기 방과후 추출 세션 두 곳(분당·위례 44곳, 수지·동안·광명 83곳). 근거: [시간대 단위 정확도와 Opus 재검토](../research/audit2/AFTERSCHOOL_V3_SLOT_AUDIT_20261024.md).

## 무엇이 바뀌나

시간표 엔진은 강좌 목록이 아니라 **학교·요일별 1학년 시간대**로 움직인다. 서울 30개교에서 강좌 행 정확도는 96%였지만 시간대 정확도는 소네트 검증 100%, Opus 재검토 99.2%(132개 중 131개)였다. 강좌명·반·기수 중복 오류는 시간대를 바꾸지 않는다.

그래서 **합격 기준과 사람 확인을 시간대에 둔다.** 추출은 지금처럼 v3 지시서(`etl/llm_extraction_spec_v3.md`)로 하고, 강좌 행도 그대로 남긴다(참고층).

## 시간대

`(종류, 요일, 시작, 종료)`. 2026학년도 학기 중 오후에 열리는 것만.

| 종류 | 포함 | 제외 |
| --- | --- | --- |
| 맞춤형 | 늘봄 초1·2 맞춤형(무료). 돌봄교실 안에서 운영하는 맞춤형 포함(`운영장소 = 돌봄내`) | 돌봄교실의 간식·휴식·자유놀이·짧은 일과 활동(한솔초 '창의활동 13:40~14:00'처럼 보육전담사가 진행하는 일과) |
| 저학년 방과후 | 대상 학년이 1학년을 포함하고 3학년 이하에서 끝나는 반 | 아침·토요·방학, 특수학급 전용, 여러 반을 합친 전체 운영 구간 |
| 전학년 방과후 | 1학년을 포함하고 4학년 이상까지 열린 반(1~6학년 등). 화면에서 빗금 | 위와 같음 |
| 학년 미기재 방과후 | 대상 학년이 적혀 있지 않은 반. 화면에서 빗금 | 위와 같음 |

1학년이 대상이 아닌 반(3~6학년 등)은 시간대가 아니다. 같은 요일·시작·종료면 강좌가 여러 개여도 시간대 하나다. 정확도 측정(맞춤형·저학년)에는 전학년·학년 미기재가 들어가지 않았으므로, 검수 때 이 둘도 함께 본다. 교시 조건("4교시 후 13:00~14:20")은 학교 객체의 `period_slots`로 적고, 요일 배정은 코드가 한다(`etl/afterschool_rules.py`).

## 학교별 합격

| 상태 | 조건 | 할 일 |
| --- | --- | --- |
| 통과 | 맞춤형 시간대가 운영 요일마다 있고, 원문끼리 다른 항목이 없음 | 적재 대상 |
| 확인 필요 | 맞춤형 행은 있는데 시각이 없는 요일이 있음 / 원문끼리 요일·시각·학년이 다름 / 원문이 PDF뿐이라 요일·시각 짝이 어긋날 수 있음 | 학교 공지·전화로 그 항목만 확인 |
| 해당 없음 | 원문에 맞춤형·저학년 방과후가 없음(이문초처럼) | 그대로 적재(시간대 0) |

원문끼리 다른 항목은 지시서의 `note`에 적는 대신 학교 객체의 **`conflicts`** 배열에 `["요일|시각|학년", "강좌·반", "L번호 / L번호"]`로 남긴다. 확인 목록이 이 배열에서 자동으로 만들어진다. 공통 시간 안내 한 줄이 강좌표 전체와 어긋나면 강좌마다 적지 말고 **원인 줄 하나로** 적는다(분당·위례 102건이 질문 20개였다, 2026-10-28).

코드가 처리하는 것(2026-10-28, `etl/afterschool_slots.py`): 같은 강좌를 40분 블록으로 이어 적은 것("13:00~13:40 | 13:50~14:30")은 한 창으로 합친다. 120분이 넘는 맞춤형 창("12:40~15:20 특기적성")은 돌봄 운영 구간으로 보고 빼며 그 요일을 맞춤형시각없음으로 남긴다. 추출은 원문대로 적으면 된다.

## 검수

- 돌봄 시간표 안 프로그램은 시각이 바로 아래·옆 줄에 따로 적혀 있을 수 있다. 일과(간식·휴식·짧은 활동) 시각을 맞춤형으로 넣지 않았는지 본다(한솔초: L87의 14:00~14:50이 맞춤형, 13:40~14:00 '창의활동'은 일과).
- 시간대만 원문과 대조한다. 학교당 중앙값 13개, 최대 25개다.
- 독립 맹검 표본은 시간대 기준으로 본다(`etl/llm_slot_audit_spec.md`). 강좌명 오류는 기록만 하고 합격에 넣지 않는다.
- 운영 적재는 사용자 확인 뒤, 시간대 층 적재 경로(`docs/research/audit2/AFTERSCHOOL_SLOT_LAYER_DESIGN_20261024.md`)가 들어간 뒤에 한다.
