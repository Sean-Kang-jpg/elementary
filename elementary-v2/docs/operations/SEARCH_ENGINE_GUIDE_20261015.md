## 2. 구글 Search Console에서 할 일

### 2-1. 배포 직후 (한 번)

1. **사이트맵 다시 제출**: 색인 생성 → Sitemaps → `https://wherecho.co.kr/sitemap.xml` 제출.
   색인 파일이 8개 하위 사이트맵을 가리킨다. 이미 있으면 "다시 제출"만 하면 된다.
2. **URL 검사 → 색인 생성 요청**. 하루 요청 수에 한도가 있으니 아래 순서로 넣는다.
   1. `https://wherecho.co.kr/guide/morning-care` (새 글)
   2. `https://wherecho.co.kr/guide/private-national` (시즌 글, 11월 6일 원서 전에 반영돼야 의미가 있다)
   3. `https://wherecho.co.kr/faq`
   4. `https://wherecho.co.kr/guide`
   5. `https://wherecho.co.kr/` (홈)
   6. 질의가 많을 만한 학교 몇 곳: 예) `https://wherecho.co.kr/school/서울-서초구-서울서초초등학교--B000002267`
3. **리치 결과 테스트**(search.google.com/test/rich-results)로 `/faq`와 `/guide/morning-care`를
   검사해 구조화 데이터 오류가 없는지 본다. `FAQPage` 리치 결과(접히는 Q&A)는 2023년부터 구글이
   정부·의료 사이트에만 보여 주므로 **검색 결과 모양이 바뀌지 않아도 정상**이다. 목적은 표시가
   아니라 AI 개요·답변 엔진이 질문과 답을 정확히 읽게 하는 것이다.

### 2-2. 1~2주 뒤 확인

- **페이지 색인 생성 보고서**를 사이트맵별로 본다(Sitemaps → 각 파일 → 페이지 색인 생성 보기).
  `pages`(21개)는 거의 전부 색인돼야 하고, `schools`·`apartments`의 비율 추이가 핵심 지표다.
- "발견됨 - 현재 색인이 생성되지 않음"이 학교·아파트에 많으면 내부 링크(허브→학교) 문제다.
  "중복, Google에서 다른 표준 페이지 선택"이 아파트에 남으면 동 단위 통합 규칙을 다시 본다.
- **실적 → 검색어**에서 아래 4절의 목표 질의가 노출되는지 필터(검색어 포함)로 본다.

## 3. 네이버 서치어드바이저에서 할 일

1. **요청 → 사이트맵 제출**: `https://wherecho.co.kr/sitemap.xml`을 다시 제출한다.
2. **요청 → 웹 페이지 수집**: 2-1의 1~5번 URL을 한 줄에 하나씩 넣는다. 네이버는 새 글을
   스스로 찾는 속도가 구글보다 느려서 이 요청의 효과가 크다.
3. **검증 → 웹 페이지 최적화**로 `/guide/morning-care`, `/guide/private-national`을 검사한다.
   제목·설명·og 태그가 정상인지 본다. 가이드 설명은 빌드가 80자 이하로 강제한다.
4. **리포트 → 사이트 진단**에서 수집 오류(특히 `/school/*` 프리렌더의 응답 시간)를 본다.
5. `robots.txt`에 네이버 전용(`User-agent: Yeti`) 블록을 손으로 넣지 않는다. 빌드 생성물이고,
   `*` 블록의 `/admin/` 차단이 Yeti에 대해 풀린다([DEPLOYMENT.md](DEPLOYMENT.md) 7절).

### 4-2. 이번에 맞춘 원칙 (다음 글에도 적용)

- **질문형 소제목 + 첫 문장에 답**: "초1은 몇 시에 학교에 가고, 몇 시에 끝나나요" 다음 줄에 바로 시각.
  AI 개요와 네이버 스마트블록은 소제목 아래 첫 한두 문장을 인용한다.
- **숫자와 기준을 함께**: "서울 223개교 중앙값 12:50", "2026학년도 운영계획 기준". 출처 없는 숫자를 쓰지 않는다.
- **확인일과 출처를 기계가 읽게**: 화면의 "근거 자료"와 같은 내용이 JSON-LD `citation`·`dateModified`로 나간다.
- **시즌 글은 연도를 제목에**: "2027학년도"가 제목에 있어야 "2027 사립초" 질의에서 날짜가 지난 글로 보이지 않는다.
  2027년 가을에는 제목과 일정을 2028학년도로 바꾼다.
