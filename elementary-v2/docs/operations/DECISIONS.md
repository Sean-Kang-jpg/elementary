# 결정 기록

사용자 결정은 **여기 한 곳**에 적는다. 대화에만 있고 여기 없으면 없는 것으로 본다. 양쪽 세션 모두 시작할 때 읽는다.
지우지 않는다. 뒤집힌 결정은 줄을 남기고 `→ YYYY-MM-DD 대체`를 붙인다. 규칙은 [AGENT_COLLAB_RR.md](AGENT_COLLAB_RR.md) 6·8절.
