# 시간표 미리 짜보기 구현 기록

상태: 로컬 구현·검증 완료, 운영 배포 전.

## 화면과 진입

- `/timetable?school=학교ID`: 학습 준비 탭 안의 독립 화면. 학교 검색 → 초1 운영 자료 확인 → 시간표 초안 편집.
- 홈 예시 카드 아래 버튼 배너, 시간표 예시 카드, 학습 준비 카드, 학교 상세의 초1 하루·돌봄 카드에서 연결한다. 정적 홈에도 동일한 배너를 넣었다.
- 관심 학교에 저장하지 않고 검색한 학교로 초안을 만들 수 있다. 관심 후보 3곳 제한과 초안 저장은 별개다.
- MY는 초안 목록과 내 시간표 표시, 편집 화면으로 가는 링크를 제공한다. 기존 기기 저장 포맷은 그대로 사용한다.
- 운영 자료가 없으면 직접 입력할 수 있다. 시간표 선택은 프로그램 신청·참여 확정을 뜻하지 않는다.

## 검증

이전 구현 세션에서 lint·typecheck·전체 build, 단위 테스트 92개, public smoke, 시간표 관련 smoke 8개를 통과했다. 모바일·데스크톱 화면과 가로 넘침도 확인했다.

시간표 smoke는 `/my` 대신 `/timetable`에서 편집기를 검사한다. `my-ux-smoke.mjs`는 MY 요약 → 시간표 편집 → MY 요약 복귀, 관심 후보 삭제 후 초안 유지, 검색으로 저장 없이 시작하는 실제 흐름을 검사한다.

agent-browser 검사는 Chrome 실행 경로를 명시했다. React 입력의 `fill` 문제는 기존 운영 화면에서도 재현되어 해당 smoke에 native setter를 사용했다. Playwright 검사는 별도 `CALENDAR_QA_PLAYWRIGHT`와 `CALENDAR_QA_CHROME` 경로 설정을 사용했다.

다른 세션의 돌봄·ETL 변경이 작업 트리에 함께 있으므로 커밋·배포 시 변경 범위를 확인해야 한다.
