# 학습·생활 준비 콘텐츠 — 기존 자료 재사용 목록 (P2-02)

작성일: 2026-10-10. 대상: P2-06 seed 작성자. 분류는 [`learning-taxonomy.json`](../../src/content/learning-taxonomy.json),
작성 규칙은 [개편 입력 문서](PLATFORM_EXPANSION_LEARNING_INPUTS.md)를 따른다. 체크 상태는
[OPERATION_PLAN](../operations/OPERATION_PLAN.md#platform-expansion)에서만 관리한다.

새 글을 쓰기 전에 아래에서 이미 확인된 사실·출처·링크 대상을 먼저 가져다 쓴다. 기존 가이드·FAQ는
행정(입학 준비) 글이라 학습 글로 옮기지 않고, **관련 글(`related`)과 본문 링크의 대상**으로 쓴다.

## 2. 체크리스트 17개 → seed 주제

체크리스트 ID는 바꾸지 않는다(보호 대상). 글은 체크 항목에서 링크하는 쪽으로 붙인다(`link` 필드는 빌드가 존재를 검사).

| 체크 항목 | 시기 | seed 후보 (분류 · 하위분류) |
| --- | --- | --- |
| `items-bag` 책가방 | 2월 중순까지 | 선택·준비물 · 사는 시기 — "책가방은 언제 사나요?" |
| `items-shoes` 실내화·주머니 | 2월 중순까지 | 선택·준비물 · 학교 안내 준비물 |
| `items-pencil` 필통·연필 | 2월 중순까지 | 선택·준비물 · 학교 안내 준비물 (학교가 정하는 경우 많음) |
| `items-bottle` 물통 | 2월 중순까지 | 선택·준비물 · 학교 안내 준비물 — "물병·실내화 선택" |
| `items-umbrella`, `items-names` | 2월 중순까지 | 같은 글에 묶음 |
| `items-desk` 책상·수납 정리 | 2월 | 선택·준비물 · 가구 — "책상은 언제 사나요?" / 환경 · 공부 자리 |
| `life-route` 등하굣길 걸어보기 | 2월 | 환경 · 등교 준비존 또는 습관 · 아침 준비 |
| `life-after` 하교 후 돌봄 계획 | 1~2월 | MY 시간표(S06·S07)가 맡는다. 글보다는 기능 |

## 4. 아직 근거가 없는 분류

환경(공부 자리·거실·정리)과 습관(아침·수면·영상) seed에 쓸 공식·전문기관 출처가 없다. 질병관리청
국가건강정보포털 '수면과 수면장애'는 본문이 스크립트로 불려 와 확인하지 못했다(2026-10-09). 사용자가
출처를 입력하기로 했다(2026-10-09 결정) — 받으면 `sources[].type`을 매겨 같은 템플릿으로 쓴다.
