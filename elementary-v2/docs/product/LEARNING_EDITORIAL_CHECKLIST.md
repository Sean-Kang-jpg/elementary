# 학습·생활 준비 콘텐츠 — 발행 전 편집 검수 (P2-07)

작성일: 2026-10-10. 대상: `src/content/learning/*.md`를 `status: published`로 바꾸기 전에 검수하는 사람.
**빌드**라고 적은 항목은 `scripts/build-content.mjs`가 막으므로 사람이 다시 볼 필요가 없다. 나머지는 사람이 읽고 판단한다.

## 1. 학교 범위

- [ ] "초1에서 배운다"는 문장마다 1학년 **교과서 단원(학기)**이 근거다. 1~2학년군 성취기준만으로 쓰지 않았다
- [ ] 2학년 내용(세 자리·네 자리 수, 곱셈, cm·m 길이 재기, 분류하기, 표와 그래프)을 초1 범위로 쓰지 않았다
- [ ] 학교 연계 표시(직접 연계/기초 준비/확장/학교과정 외)가 판정 기준에 맞고 근거 단원이 적혀 있다 — 표시·근거 유무는 **빌드**
- [ ] 영어는 '학교과정 외'다 — **빌드**. 본문에서도 "초1 대비"라는 말을 쓰지 않았다
- [ ] 2027년 3월 교과서 배포 뒤 단원명을 다시 확인할 글이면 그 안내가 있다

## 2. 불안·선행 경쟁

- [ ] 입학 전에 "여기까지 해야 한다"는 도달 목표를 제시하지 않았다. "학교는 이것을 이때 가르친다"를 말하고 판단은 부모에게 둔다
- [ ] 다른 아이와의 비교, 진도·점수·등수를 쓰지 않았다
- [ ] 금지 표현(뒤처, 필수 선행, 선행 필수, 안 하면 늦, 남들보다, 상위권, 최소한 여기까지, 반드시 끝내) — **빌드**. 목록에 없는 비슷한 말도 사람이 본다
- [ ] '우리 집이라면'이 한 가지 정답이 아니라 아이 상황별 갈래(관심 있음/없음/이미 함)로 되어 있다

## 3. 사실·판단·반응의 구분

- [ ] '학교에서는 이렇게 배워요' 같은 사실 절에는 근거 자료에 있는 내용만 있다
- [ ] '좋은 점·아쉬운 점·우리 집이라면'은 편집 판단이다 — 화면 하단 안내 문구가 자동으로 붙는다
- [ ] 부모 반응은 `signals`에만 있고 본문에 후기 인용·빈도("많은 부모가")를 쓰지 않았다
- [ ] 반응이 없으면 없다고 둔다 — 화면이 "아직 모은 반응이 없어요"를 보인다. 긍정 후기에서 단점을 뽑아 부정 반응으로 만들지 않았다
