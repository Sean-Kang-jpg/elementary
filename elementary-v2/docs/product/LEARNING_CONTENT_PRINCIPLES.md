# 어디초 학습 콘텐츠 편집 원칙 v1.0

Status: **확정 (2026-10-05)** · 대상: 2027학년도 초등학교 입학생 · 다음 확인: 2027년 3월(교과서 배포 후)

입학 준비 탭의 "1학년 미리보기"가 따르는 원칙이다. 커리큘럼 공유 설계
([`PRD_CURRICULUM_SHARING.md`](PRD_CURRICULUM_SHARING.md))는 따봉·순위 중심이었고, 이 문서가 그
방향을 바꾼다. 코드는 `VITE_CURRICULUM_ENABLED` 뒤에 있다.

## 한 문장

> 초1 교육과정을 선행학습 목표가 아닌 **기준점**으로 삼고, 아이의 현재 시작점을 고려해 학교 학습의
> 기초 준비·직접 연계·확장·학교과정 외를 구분하여, 제휴·협찬 표기가 확인되지 않은 실사용 후기와
> 함께 콘텐츠를 소개한다.

## 1. 기준: 국가교육과정 → 실제 초1 교과서 → 아이 현재 수준

**성취기준을 그대로 "초1 정답"으로 쓰지 않는다.** 1~2학년 성취기준은 두 학년을 묶어 정한다. 예를 들어
수학 1~2학년군에는 네 자리 수와 곱셈구구가 있지만, 1학년 교과서는 100까지의 수와 두 자리 수 덧셈·뺄셈까지다.
1~2학년 국어·수학은 **국정 교과서**라 교과서가 하나뿐이므로, 1학년 범위는 그 단원으로 정한다.

| 근거 | 쓰는 곳 | 출처 |
| --- | --- | --- |
| 교과·시간 배당 | 1~2학년 교과는 국어·수학·바른 생활·슬기로운 생활·즐거운 생활. 영어는 3~4학년군부터(136시간). 국어 1~2학년군 482시간 | 교육부 고시 제2022-33호 [별책 2] 초등학교 교육과정 |
| 성취기준 | 단계마다 관련 성취기준 코드와 문장 | [별책 5] 국어과, [별책 2] 안의 수학과 |
| 입학 초기 | "1학년 학생의 학교생활 적응 및 한글 해득 교육 등의 입학 초기 적응 프로그램" 운영 | [별책 2] 총론 부분 |
| 한글 지도 순서 | 낱자 → 글자 → 단어 → 문장, 받침 없는 글자 → 받침 있는 글자, 소리와 표기가 같은 단어 → 다른 단어 | [별책 5] 성취기준 적용 시 고려 사항 |
| 1학년 단원 | 1-1 국어 첫 단원 '한글 놀이' 34차시, 학기별 국어·수학 단원 | 경상남도교육청, 「2022 개정 교과 교육과정 도움자료(초등 1,2학년군)」(2024-12) |

**주의**: 교육청 도움자료는 국정 교과서 **현장검토본**을 참고했다고 밝힌다. 최종 교과서와 일부 다를 수
있으므로 2027년 3월 교과서 배포 뒤 단원명을 다시 확인한다.

2026년 1월 개정(국가교육위원회고시 제2026-1호, '건강한 생활' 신설)은 초1~2에 **2028년 3월**부터 적용된다.
2027학년도 입학생 기준에는 넣지 않는다. 공개 페이지에 쓸 때는 고시 원문을 출처로 붙인다.

## 2. 판단 구조

1. 초1에서 실제로 무엇을 **언제** 배우는가 (교과서 학기·단원)
2. 이 아이는 지금 어디까지 할 수 있는가 (부모가 고르는 현재 수준)
3. 이 콘텐츠는 그 사이에서 무엇을 돕는가 (학교 연계 표시)
4. 실제로 쓴 부모들은 어떻게 평가했는가 (근거 후기)

**"목적지"는 입학 전에 도달해야 한다는 뜻이 아니다.** 화면은 "입학 전 여기까지 하세요"가 아니라
"학교에서는 이것을 이때 배웁니다"를 말한다. 판단은 부모가 한다.

## 3. 과목과 단계

단계의 공식 근거와 단원 매핑은 `src/content/learning/stages.json`이 원본이다. 요약:

- **국어** 한글 해득 → 받침 있는 글자 → 낱말 읽기·쓰기 → 문장 읽기·쓰기 → 내용 이해 → 간단한 쓰기(그림일기)
- **수학** 수 감각 → 덧셈·뺄셈 → 비교·측정 → 모양·공간 → 규칙
- **영어** 학교 교과는 3학년부터라 **"초1 대비"로 표시하지 않는다.** 가정 영어 progression(노출 → 알파벳 →
  소리·파닉스 → 단어 읽기 → 초기 리딩)으로 따로 둔다. 1·2학년 방과후 영어는 2019년 공교육정상화법 개정으로 허용됐다

## 4. 학교 연계 표시 — 판정 기준

콘텐츠마다 하나를 붙인다. **표시마다 근거 단원이나 성취기준을 함께 기록한다** — 기준 없이 붙이면 항목마다 달라진다.

| 표시 | 판정 기준 | 기록할 근거 |
| --- | --- | --- |
| **초1 직접 연계** | 1학년 교과서 단원의 학습 목표와 같은 내용을 같은 범위에서 다룬다 | 단원(예: 1-2 '100까지의 수')과 성취기준 코드 |
| **기초 준비** | 1학년 단원을 시작하는 데 바탕이 되는 경험을 준다. 단원 목표 자체를 가르치지는 않는다 | 이어지는 단원 |
| **확장 활동** | 1학년 범위를 넘거나 옆으로 넓힌다(사고력·퍼즐·심화) | 넘는 범위(예: 2학년 '세 자리 수') 또는 확장 방향 |
| **학교과정 외** | 학교 수업 대비가 목적이 아니다 | 해당 없음 — 영어 전부가 여기 |

## 5. 아이 현재 수준

점수나 "초1 대비 몇 %"를 붙이지 않는다. 선행 정도의 평가가 아니라 **시작할 콘텐츠를 고르는 정보**다.
선택은 기기에만 저장한다(PRD v2 D1).

- 국어: 글자를 익히는 중 / 낱말을 읽음 / 짧은 문장을 읽음 / 짧은 글을 혼자 읽고 이해함
- 수학: 수를 세고 수량을 연결하는 중 / 10 안의 수를 이해함 / 간단한 덧셈·뺄셈을 함 / 50~100까지의 수와 연산에 익숙함
- 영어: 주로 듣는 단계 / 알파벳을 알아봄 / 글자와 소리를 연결함 / 간단한 단어를 읽음 / 짧은 영어책을 읽음

## 6. 후보가 되는 콘텐츠

**유형 5종**: 영상 / 문제집·워크북 / 책·리더스 / 교구·장난감·보드게임 / 부모와 하는 활동·프린트.
**제외**: 종합 패드 학습·온라인 강의 구독 서비스.

후보는 **명확한 목적이 하나 이상** 있어야 한다. "연산을 반복한다", "받침 글자를 익힌다"는 되고,
"7세에게 좋아요"는 안 된다.

## 7. 근거

### 근거 등급

| 등급 | 무엇 | 쓰임 |
| --- | --- | --- |
| **P. 공공 추천** | 교육청·교육부·EBS 등 공공 기관이 수업·가정 학습용으로 소개한 것 | 강한 근거. 출처 문서와 쪽수 기록 |
| **A. 독립 장기 사용 후기** | 연령·사용 기간·결과가 구체적 | 핵심 추천 근거 |
| **B. 독립 일반 사용 후기** | 직접 사용은 명확하지만 기간이 짧음 | 핵심 추천 근거 |
| **C. 구매자 리뷰** | 서점·쇼핑몰 구매평 | 보강 자료 |
| **D. 공식 정보** | 출판사·제작사 | 사양 확인에만 |

### 제외하는 후기

쿠팡 파트너스·제휴 마케팅·구매 수익 링크·추천인 코드, 제품·도서 무료 제공, 원고료, 체험단, 협찬,
서포터즈, 브랜드 앰배서더, 리뷰어클럽 등 제공형 리뷰, 출판사·브랜드가 쓴 후기성 콘텐츠.
**긍정이든 부정이든 똑같이 제외한다.**

### 표기

"비광고 후기"라고 쓰지 않는다. **"제휴·협찬 표기 확인되지 않음"**이라고 쓴다. 표기가 없다고 이해관계가
없다고 보장할 수는 없다.

### 후보 하나당 목표

잘 맞았던 사례 2~3, 아쉬웠던 사례 1~2. 아쉬운 사례가 없으면 "아쉬운 사례를 충분히 확인하지 못했습니다"라고
쓴다. 긍정 후기에서 단점을 뽑아 부정 후기 1건으로 만들지 않는다.

### 저장 범위 — 본문을 옮기지 않는다

후기마다 저장하는 것은 **원문 URL과 속성**뿐이다: 등급, 7세 사용 여부, 사용 기간, 완북·중단, 부모 개입도,
장점 요약, 아쉬움 요약(각 한 줄, 우리 말로), 제휴·협찬 표기 확인 결과, 확인일. 본문 인용과 작성자·아이에 관한
개인 정보는 저장하지 않는다.

### 수집 방법 — 사람이 읽는다

**네이버 검색(`search.naver.com`)과 블로그(`blog.naver.com`)는 robots.txt로 모든 봇을 막고, AI 검색·RAG 목적
접근을 명시적으로 금지한다(ClaudeBot 포함).** 국가교육과정정보센터(`ncic.re.kr`)도 검색엔진 몇 곳 외의 봇을
막는다. 그래서:

- 후기는 **사람이 브라우저에서 찾아 읽고**, 정해진 양식(`docs/research/LEARNING_PILOT_CANDIDATES.md` 3절)으로 기록한다
- 자동화 도구나 AI 에이전트로 네이버 검색·블로그를 수집하지 않는다
- 공식 문서는 접근을 막지 않는 곳(교육청 게시판 등)에서 받는다
