## A2 — 1~2학년군 성취기준 ≠ 실제 초1 범위 → P2-07, P2-06(배움)

1~2학년 성취기준은 두 학년을 묶는다. 수학 1~2학년군에는 네 자리 수·곱셈구구가 있지만 **1학년 교과서는 100까지의
수와 덧셈·뺄셈까지**다. 1~2학년 국어·수학은 국정 교과서라 1학년 범위는 그 단원으로 정한다. 배움 콘텐츠의
"초1에서 배운다" 문장은 단원(학기)을 근거로 쓰고, 성취기준만으로 쓰지 않는다. 2학년 내용(세 자리·네 자리 수,
곱셈, cm·m 길이 재기, 분류하기, 표와 그래프)을 초1 범위로 표기하지 않는다.

## A5 — 부모 반응 신호의 표기·저장 규칙 → P2-04, P2-05

- "비광고 후기"라고 쓰지 않는다. **"제휴·협찬 표기 확인되지 않음"**이라고 쓴다. 표기가 없다고 이해관계가 없다고 보장할 수 없다
- 제외: 쿠팡 파트너스·제휴 마케팅·구매 수익 링크·추천인 코드, 제품·도서 무료 제공, 원고료, 체험단, 협찬, 서포터즈,
  앰배서더, 리뷰어클럽, 출판사·브랜드 작성 후기. **긍정이든 부정이든 똑같이 제외**
- 긍정 후기에서 단점을 뽑아 부정 신호 1건으로 만들지 않는다. 부정 신호가 없으면 "아쉬운 사례를 충분히 확인하지 못함"
- 저장은 원문 URL과 속성만: 7세 사용 여부, 사용 기간, 완료·중단, 부모 개입도, 장단점 요약(각 한 줄, 우리 말로), 표기 확인 결과, 확인일. 본문 인용·작성자/아이 개인 정보는 저장하지 않는다
- 근거 등급: A 독립 장기 사용(연령·기간·결과 구체적) / B 독립 일반 사용 / C 구매자 리뷰(보강용) / D 공식 정보(사양 확인용) — 여기에 A4의 공공 추천을 더한다

## A6 — 돌봄 데이터는 시간표 엔진의 입력 → A2-E03·E04, A2-S02

운영 중인 SQL `23` 데이터를 그대로 쓴다.

- `school_care_statistics`(학교알리미 apiType=59, 6,266개교): 오후·저녁·연계형 돌봄 교실 수와 참여 인원, 방과후 특기적성·교과 프로그램 수, `statistics_year`(공시연도 `pbanYr` — 어느 학년도 실적인지 미확인), `snapshot_date`
- `care_centers` + `nearby_care_centers()`(다함께돌봄·우리동네키움센터 1,483곳): 학기·방학 운영시간, 정원, 센터 자가입력 수정일

없는 것: 신청·대기·탈락 인원, 강좌 목록·시간, 대상 학년. Audit 2 §7의 원칙대로 참여 인원 비율을 **선정 가능성 근거로 쓰지 않는다**.

**전교생 120명 미만 학교에 한해 안내 문구를 붙인다.** 운영 데이터(2026-10-04)에서 1·2학년 대비 참여가 100%를 넘는
학교 1,473곳은 거의 모두 이 구간이었다(60명 미만 75%, 60~120명 42%, 300명 이상 1% 이하). 작은 학교는 돌봄을
전 학년에 여는 경우가 흔하다. 문구 예시(현재 학교 상세 `SchoolCarePanel`):

> 학생이 적은 학교는 돌봄을 전 학년에 여는 경우가 흔해 1·2학년 대비 이용률을 계산하지 않습니다.

시간표 엔진에서는 "이 학교 돌봄은 전 학년 대상으로 운영될 수 있어, 1학년 자리 여부는 학교 안내문으로 확인하세요" 정도로
쓴다. 120명 이상 학교에는 이 문구를 붙이지 않는다.

## A7 — 익명 로그인을 쓰면 공개 조회의 역할이 바뀐다 → P3-04, A2-B04

Supabase 익명 사용자는 `authenticated` 역할이다. 브라우저에 세션이 생기면 그 뒤 모든 요청이 `anon`이 아니라
`authenticated`로 나간다. 익명·Kakao·Google 어느 로그인이든 **로그인 상태에서 공개 테이블·함수가 그대로 읽히는지**를
회귀 검사에 넣는다. 2026-10-05 기준 SQL 13~23의 함수 grant는 `anon, authenticated` 둘 다이고, `school_master`·
`school_apartment_serving`의 SELECT policy는 역할 지정이 없지만, 실제 테이블 grant는 로그인 상태로 확인하지 않았다.

Cloudflare Turnstile을 붙인다면 Vercel의 사이트 키와 Supabase Auth captcha 설정을 **함께** 켠다. captcha만 켜고
사이트 키가 없으면 새 사용자 로그인이 전부 막힌다.

## B11 — 빌드 시점 콘텐츠 검증 → P2-08, P2-04
