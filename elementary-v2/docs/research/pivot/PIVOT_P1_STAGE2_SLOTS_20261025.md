## 분리해서 보존한 확인 사항

- 같은 종류·요일·시각을 여러 강좌가 공유하면 시간대1개로 합쳤다. 강좌 이름·반 이름 차이만으로 시간대 오답을 만들지 않았다.
- 원문 시각 충돌과 요일·학년 충돌을 학교 객체 `conflicts` 배열로 옮겼다. 오리 요약표/수요일 주간표, 서당 본문 토요일/주간표 월요일, 분당 본문·표의 학년 편성 차이도 근거 줄을 연결했다. 기존 sidecar의 대안은 유지했다.
- 맞춤형 교시 조건은 `period_slots`로 보존한다. 이번 실행에서는 DB나 요일별 교시 수를 읽지 않아 요일 배정은 미해결이다. 유료 강좌의 공란을 맞춤형 교시 조건으로 채우지 않는다.
- 돌봄 활동에 시간이 있어도 같은 요일 독립 맞춤형에 공란이 있으면 확인 필요로 남긴다. 돌봄 입급 조건을 모든 학생에게 적용 가능한 시간대로 바꾸지 않는다.
- 조건부 개설과 PDF만 있는 학교는 자동 확인 목록에 남긴다. PDF 표를 이미 읽었어도 이번 자동 목록만으로 해당 경고를 해제하지 않았다.
- 초림·양영의 추가 학기 자료는 별도 검수 기록을 유지하며 기존 연간 행에 중복 합산하지 않았다. 최신 학기 자료를 핵심 후보에 연결하는 후속 확인이 필요하다.
