## 현재 판정

① 시험 5개교의 참여 단위 게이트는 재실행해 통과했다. ②는 **39개교 전체 입력 확보·무손실 분할 완료**, **학교 전체 v3 추출·검수 완료 0/39**, 독립 표본 맹검 미실행이다. 이번 결과를 ② 완료나 운영 적재 승인으로 사용하지 않는다. ③ 83개교는 미착수다.

- 입력 준비 매니페스트: `p1_stage2_inputs_20261023.json`.
- 추가 공식 원문 출처: `p1_stage2_sources_20261023.json`. PDF·이미지·HWP의 로컬 원문은 매니페스트 경로에 보존했다.
- 무손실 검수 자료: `p1_stage2_packets_20261023.json`; 원문 전체와 151개 분할을 `etl/runtime/pivot_p1_stage2_packets_20261023_v2/`에 보관했다. 분할은 원문 행을 누락하거나 합치지 않는다. 분할 자체는 읽기·검수 완료 표시가 아니다. 서당의 8월 시간표 이미지 2장은 텍스트 변환본에 포함되지 않으므로 검수 자료의 별도 이미지 의존성으로 연결하고 해시를 검사한다. 이미지를 확인하지 않고 텍스트만으로 학교 검수를 완료하면 안 된다.
- 선택한 자료의 직접 대조 기록: `p1_stage2_supplemental_review_20261023.json`. 서당 이미지 2장과 미금 3분기 맞춤형 PDF 2쪽을 시각 확인했다. 두 학교 전체 목록의 완전성 검수를 대신하지 않는다.

### 성남미금초

[9월 17일 게시, 9월 16일 작성한 3분기 맞춤형 신청 안내](https://www.goesn.kr/snmg-e/na/ntt/selectNttInfo.do?mi=11204&nttSn=1956017)를 확보했다. 9월 28일~2027년 1월 17일 적용, 1월 18일 겨울방학식 미운영이며 겨울방학 프로그램은 별도 안내다.

**맞춤형은 특정 과목 선택 수강이 아니다.** 매일 2차시 참석이 기본이고, 특정 과목 선택은 교내 방과후 수업을 이용하도록 원문이 명시한다. `class_day_bundle`로 기록했으며 돌봄 입급학생은 대상에서 제외된다. 주5일·2차시 참가자가 우선이고, 요일 선택·부분 참가에는 순위와 퇴실 조건이 있다. 과목명 하나를 클릭하면 자유롭게 수강 가능한 것처럼 표현하면 안 된다.

연간계획의 과목표는 명시적인 예시이고, 5월 공개수업의 실제 과목 배정과 다르다. 5월 자료로 2학기 과목 요일을 채우지 않았다. 9월 10일 수익자 방과후 3분기 안내는 확보했지만 개별 반 전체 대조는 아직 완료하지 않았다.

## 시험 처리 결과를 폐기한 이유

구조화 표를 자동으로 읽는 보조 규칙을 39개교 전체 입력에 시험 실행했다. 30개교에서 1,891개 후보 행이 나왔고 9개교에서는 후보가 없었다. 원문 표본 대조에서 병합 셀 이동, 유형·학기·아침/방학 문맥 상속 오류, 날짜의 학년 오인, 강좌명 훼손·강사명 잔존이 드러나 **전량 불채택**했다. 이 수치를 v3 추출 성과나 강좌 수로 사용하지 않는다. 이 규칙은 커밋에 포함하지 않았다.

`p1_stage2_trial_rejected_20261023.json`에 진단을 남겼고, 로컬 시험 결과는 `rejected_diagnostic_only`로 표시했다. 후보가 없는 학교를 ‘강좌 없음’으로 처리하지 않았다.

| 실패 분류 | 학교 | 후속 원문 처리 |
| --- | --- | --- |
| PDF 표 평탄화 | 불곡·서현·안말·양영·초림 | 원본 PDF 페이지의 열·병합 셀 재구성, 필요시 현재 학기 신청 안내 대조 |
| PDF 평탄화 + 이미지 시간표 | 서당 | 8월 2학기 이미지 확보·위 범위 직접 대조; 나머지 전체 목록 대조 필요 |
| 과도한 필터링 | 수내 | 수강료 표에 교재명 열이 있다는 이유로 시간표 전체를 버린 오류; 원문 강좌 표를 다시 읽음 |
| 주간표 헤더 미지원 | 청솔 | 학년별 HWP 주간표 원문 대조 |
| 유형 제목 문맥 미인식 | 위례푸른 | HWP 수익자 표의 유형을 원문으로 확정 |

후보가 나온 다른 30개교도 동일 오류 가능성이 있어 모두 미검수 상태다. 전체 문서 입력을 보존한 검수 자료로 재개한다. 표가 없는 것이 아니라 추출 규칙이 지원하지 못한 경우를 분리했다.

## 작업 경계와 남은 순서

전용 worktree·브랜치 `codex/pivot-p1-v3-20261021`만 편집했다. master의 academy 설정·공통 입력 사전검사·기타 미커밋 파일은 읽기 확인만 했다. 현재 master와의 커밋 차이는 프런트야드·학원/화면 작업이며 이번 파일과 겹치지 않는다. 다른 팀원 파일을 가져오거나 변경하지 않았다.

운영 DB·SQL32·운영 적재기·P2·화면·운영 원본은 이번 변경 대상이 아니다. 이번 커밋은 원문 출처·부분 대조·검수 자료 생성기·테스트에 한정된다.

1. 39개교 전체 v3 추출: 모든 원문 행을 읽고 고학년·아침·방학·폐강·기수까지 포함해 14칸 원시 행 및 참여 단위 검수 sidecar를 작성한다. 보조 규칙의 불채택 후보를 전용 출력으로 복사하지 않는다.
2. 서당 신청 조건과 미금 현 학기 정규 교과 요일 등 미확인 항목은 동일 적용 기간의 공지로 보완한다. 과목별 신청인지 학급·요일 묶음인지, 돌봄 입급 내부 활동인지를 학교별로 근거와 함께 기록한다.
3. 독립 5개교 표본 맹검을 실제 수행하고 결과를 받는다. 같은 에이전트의 재읽기를 독립 검증으로 표시하지 않는다.
4. 참여 단위가 운영 loader·화면과 연결된 로컬 미리보기를 검수한 뒤에만 운영 반영 여부를 다룬다. 현재 운영 반영 승인은 없다.
