## 후속 추출 batch03·04

범계초 24행, 온신초 10행, 안양관악초 19행, 서면초 32행, 용인대덕초 12행을 추가했다. 누적 12개교 291행(방과후 266, 맞춤형 25)이며 신규 대상 71개교가 미추출이다. 프로그램 목록·40분 구간을 포함하므로 행 수는 독립 강좌 수와 다르다.

- 온신초의 한 줄로 합쳐진 표는 행별 문자 범위를 근거로 저장했다. 검사기는 해당 범위 안에서만 학년·요일·시각을 확인한다.
- 안양관악초는 상세표와 다른 목록의 강좌명 불일치를 보존했다.
