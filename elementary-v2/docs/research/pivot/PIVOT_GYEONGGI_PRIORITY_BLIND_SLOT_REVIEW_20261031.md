# 경기 우선 83곳 시간대 독립 맹검 — 표본 10곳 (2026-10-31)

추출 담당과 다른 검수자(소네트 하위 에이전트, 학교마다 따로)가 원문 한 파일만 읽고 1학년 오후 시간대를 직접 정리했고, 추출 결과에서 만든 시간대와 비교는 코드로 했다. 검수자는 추출 결과를 보지 않았다. 지시서와 답안, 비교 결과는 [blind_slot_review_20261031/](blind_slot_review_20261031/)에 있다. 기준은 [파일럿 수집 기준](../../operations/PIVOT_SLOT_STANDARD.md)이고, 분당·위례 맹검(5곳 표본)과 같은 방식이다.

## 호성초 — 정정함

추출이 방과후 19부서의 대상 학년을 모두 비워(학년미기재) 넣었다. 원문에는 2026 개설 수요조사표(L711~719)에 부서마다 학년이 있고(대부분 1~6학년, 기타연주 3~6학년, 플룻 2~6학년), 컴퓨터는 교재표(L899~902)에 A반 1-2학년·B반 3-6학년이 있다. 그래서

- 1학년이 대상이 아닌 반(플롯 A/B, 기타연주 A/B, 컴퓨터 응용·자격증)이 시간대에 들어가 있었다. 그중 수 13:50~15:20(플롯 B)은 다른 강좌가 없는 창이라 잘못된 시간대가 하나 생겼다.
- 나머지는 전학년방과후(빗금)로, 컴퓨터 기초는 저학년방과후로 바뀌었다.

`build_batch51.py`를 고쳐 다시 만들었다(19 → 20 시간대). 정정 뒤 맹검과의 차이는 컴퓨터 기초(1-2학년)의 저학년 창 두 개뿐이고, 같은 시각의 전학년 창은 맹검에도 있다. 컴퓨터 기초 = 교재표 A반이라는 대응은 교재 수준으로 추정했으므로 검수 항목(`computer_class_grade_mapping`)으로 남겼다.

## 광명광덕초 — 기준 차이

수요일 맞춤형이 종이접기 13:00~13:40, 컴퓨터 13:50~14:30으로 강좌가 다르다. 빌더는 같은 강좌의 이어지는 블록만 합쳐서 창이 둘이 되고, 맹검은 "정규수업 후 2차시 90분"(L688)을 근거로 13:00~14:30 하나로 적었다. 데리러 가는 시각(14:30)은 같다. 빌더 규칙은 바꾸지 않았다(다른 강좌를 합치면 분당·위례에서 고친 잘못된 병합이 되살아난다).

## 결론과 한계

- 표본 10곳에서 실제 추출 오류는 1곳(호성초)이었고, 원인은 대상 학년을 다른 표에서 찾지 않은 것이다. 같은 유형(학년미기재방과후 시간대가 있는 학교: 대현·용인신촌·죽전·광명광덕·안현)은 사람 확인 때 원문의 다른 표(수요조사·교재·수강료 표)에 학년이 있는지 본다.
- 이것은 표본 검수다. 83곳 전체가 독립 검수를 받은 것은 아니며, 확인 필요 50곳 282항목은 원문만으로 풀리지 않아 학교 공지·전화가 필요하다. 현재 학기 변경 공지 확인도 하지 않았다.
