## 확인 기준 변경

- 요일·시각 충돌은 파생 학교 객체의 `conflicts`에 `[축, 강좌·반, L번호 / L번호]` 형식으로 저장했다. 확인 목록은 이 배열과 시간대 빌더 결과에서 생성했다.
- 안양관악 강좌명 차이, 안서 동일 강좌 중복은 참고층 기록으로 보존하되 시간대 합격의 독립 사유로 쓰지 않는다. 안서는 별도의 수업 길이 충돌이 남는다.
- 광문 돌봄 종료17/19시 차이는 돌봄 필드의 보완 사항으로 유지하며 수익자 강좌 시간대에 섞지 않는다. PDF-only 확인 항목은 별도로 유지한다.
- 광명북 맞춤형은 실제 이름만 확인되고 예시표 시각은 채우지 않았다. 맞춤형시각없음5요일로 자동 표시한다.
- 서면 영어 A반은 HWP 원본 문단까지 확인했으나 수·금 시각의 요일표기는 없었다. 해당 미확인은 유지한다.
- 교시 조건이 없는 학교에 `period_slots`를 생성하지 않았다. 공시 요일별 교시 맵 없이 추정 시각을 넣지 않는다.
