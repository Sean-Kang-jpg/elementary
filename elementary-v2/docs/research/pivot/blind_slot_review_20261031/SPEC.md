# 1학년 오후 시간대 맹검 지시서 (경기 우선 83곳 표본, 2026-10-31)

입력은 원문 한 파일뿐이다: `etl/runtime/pivot_gyeonggi_priority_20261023/prepared_v3/inputs/<school_id>.txt`.
학교알리미 15-라 첨부 전체이고 줄마다 `L번호:`가 있으며, 각 첨부 앞에 `[file: …; academic_year: …]` 머리줄이 있다.
이 파일 외에는 아무것도 읽지 않는다. 특히 같은 폴더나 `outputs/`, `docs/research/pivot/`의 다른 추출 결과를 열지 않는다.

## 시간대란

부모가 1학년 시간표를 짤 때 쓰는 **요일별 시간 창** `(종류, 요일, 시작, 종료)`. 2026학년도 학기 중 평일 오후에 열리는 것만.

| 종류 | 포함 |
| --- | --- |
| 맞춤형 | 늘봄 초1(·2) 맞춤형 프로그램(무료). 돌봄교실 안에서 운영하는 맞춤형도 포함 |
| 저학년방과후 | 대상 학년이 1학년을 포함하고 3학년 이하에서 끝나는 방과후 반(1학년, 1~2학년, 1~3학년) |
| 전학년방과후 | 1학년을 포함하고 4학년 이상까지 열린 반(1~6학년, 전학년) |
| 학년미기재방과후 | 대상 학년이 적혀 있지 않은 방과후 반 |

시간대가 아닌 것: 아침·토요·방학 강좌, 특수학급 전용 반, 2025학년도 이전 자료(머리줄 academic_year가 2025이거나 제목이 2025학년도인 표),
1학년이 대상이 아닌 반(2~6학년, 3~6학년 등), 여러 반을 합친 전체 운영 구간("13:00~17:20 4개 반"), 돌봄교실의 간식·휴식·자유놀이·
보육전담사가 진행하는 짧은 일과 활동, 120분을 넘는 돌봄 운영 구간("12:40~15:20 특기적성" 같은 돌봄 하루 범위).

규칙:
- 같은 요일·같은 종류·같은 시작·종료면 강좌가 여러 개여도 시간대 하나다.
- 같은 강좌를 40분 블록으로 이어 적은 것("13:00~13:40 | 13:50~14:30")은 한 창(13:00~14:30)으로 적는다.
- 오후 시각이 12시간제로 적혀 있으면(1:40) 24시간제(13:40)로 바꾼다.
- 시각이 "4교시 날 13:00~, 5교시 날 13:50~"처럼 교시 조건으로만 있고 어느 요일이 4교시인지 원문에 없으면 시간대로 만들지 말고 `undeterminable`에 적는다.
- 학기별로 시각이 다르면 원문에 있는 2026 현재 학기(2학기 표가 있으면 2학기) 것을 쓰고 `note`에 적는다.
- 원문끼리 요일·시각이 다르면 강좌표(반별 상세표) 쪽을 적고 `conflicts`에 두 줄 번호를 적는다.

## 할 일

원문을 처음부터 끝까지 읽고 위 정의대로 이 학교의 시간대를 모두 정리한다. 엄격하게, 원문 근거가 있는 것만 적는다.

## 출력

지정된 경로에 JSON 객체 하나를 쓴다(UTF-8):

```json
{
  "school_id": "B000000000",
  "slots": [["맞춤형", "월", "13:50", "15:10", [88, 89]], ["저학년방과후", "화", "13:50", "15:00", [291]]],
  "custom_untimed_weekdays": ["수"],
  "undeterminable": ["맞춤형은 4교시 날 13:00~14:20, 5교시 날 13:50~15:10 (L60) — 요일별 교시 없음"],
  "conflicts": [["시각", "웹툰 A반", "L520 / L537"]],
  "note": "한 줄, 없으면 null"
}
```

- `slots`의 마지막 칸은 근거 L번호 목록이다.
- `custom_untimed_weekdays`: 맞춤형 프로그램이 그 요일에 있는데 시작·종료 시각이 원문에 없는 요일.
- 담당자·강사·학생 이름, 전화번호는 옮기지 않는다. 다른 파일은 만들거나 고치지 않는다.
