# P1 ② 독립 표본 시간대 검수 절차

2026-10-25 사용자 지정 `docs/operations/PIVOT_SLOT_STANDARD.md`를 적용한다. 기존 행 정확도 절차를 시간대 기준으로 대체했다. v3 강좌 행은 참고층으로 보존한다.

표본은 결과 열람 전에 고정한 백현·신백현·한솔·성남송현·불정 5곳이다. 원 추출 담당자는 자기 학교를 검수하지 않는다. 결과를 미리 보았다면 독립 맹검으로 인정하지 않는다.

## 원문 기대값 선동결

검수자는 번호가 붙은 학교 원문 전체를 먼저 읽는다. 해당 학교의 결과·담당자 sidecar·누적 리뷰·슬롯 후보는 열지 않는다. `etl/llm_slot_audit_spec.md`의 정의대로 2026학년도 학기 중 오후의 `(종류, 요일, 시작, 종료)`를 스스로 정리한다. 맞춤형은 돌봄내 맞춤형도 포함하고 간식·휴식·자유놀이·짧은 일과는 제외한다. 저학년 방과후는 1학년을 포함하고 대상 상한이 3학년 이하인 반만 포함한다. 1~6학년·학년 미기재 유료 강좌는 이번 정확도 분모에 넣지 않는다.

학교별 `p1_stage2_blind_<school_id>_expected_20261025.json`에 검수자·입력 지문·실제 전체 읽은 줄 범위·결과 사전 미열람 선언·기대 시간대·근거 L번호·원문만으로 결정 불가 항목을 저장한다. 저장 직후 SHA256을 부모에게 전달하고 파일을 동결한다. 교시 조건은 요일을 추측하지 않고 별도로 기록한다.

## 슬롯 후보 대조

기대값 파일 동결 뒤에만 `p1_stage2_slot_candidates_20261025/<school_id>.json`을 열어 비교한다. 원문과 슬롯 후보 두 입력으로 `etl/llm_slot_audit_spec.md`의 JSON 판정 형식을 사용한다. 기대값은 결과 파일이 아니라 선독 단계의 검수 기록이다. 강좌 raw/추출 담당자의 판정으로 답을 맞추지 않는다.

비교 결과는 `p1_stage2_blind_<school_id>_comparison_20261025.json`에 저장한다. 필드는 `school_id`, `my_slot_count`, `verdicts`(후보 번호별 ok 또는 wrong·이유와 L번호), `missing`, `undeterminable`, `note`이며 기대값·후보의 SHA256도 연결한다. 모든 후보를 한 번씩 판정한다. 잘못된 이유는 요일·시각·대상아님으로 분류한다. 강좌명·반명·기수 표현 차이는 참고 기록이며 시간대가 같으면 오답으로 계산하지 않는다.

## 통합 판정과 보호 범위

시간대 정확도는 올바른 후보 수 / 전체 후보 수로 보고하고 빠진 시간대 수를 별도로 보고한다. 0개교의 정확도를 100%로 만들지 않는다. 원문 미공시·원문 간 충돌·교시별 요일 미배정은 추출 오류와 구분해 확인 목록에 남긴다. 5개교 모두 끝나기 전에는 표본 검증 완료로 표시하지 않는다. 실제 운영 반영은 별도 사용자 확인과 시간대 층 적재 경로 준비 뒤 진행한다. DB·운영 적재기·P2는 변경하지 않는다.
