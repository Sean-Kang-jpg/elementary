# 배움·돌봄 우선 노출 원천 검토

확인일: 2026-10-28. 이번 작업은 원천 분석이며 화면·운영 DB 정렬은 변경하지 않았다.

후속 전체 엑셀 대조는 [실측 결과](SHUTTLE_GRADE_MATCH_AUDIT_20261028.md)를 기준으로 한다. 셔틀 수집·매칭은 후속 작업에서 완료했고, 초1 후보 규칙과 기관 종류별 원천 한계도 추가 확인했다.

## NEIS 실제 분포

로컬 최신 원천 `etl/runtime/academy/acainsti_scope_20261007.json`은 17개 시도 138,542행이다. 직업기술 3,938행을 제외하면 기존 노출 범위는 134,604기관이며 교육청 코드+지정번호 키도 134,604개로 중복이 없다. 최신 실시간 현황을 재수집한 결과는 아니다.

`LE_CRSE_LIST_NM`, `LE_CRSE_NM`, `PSNBY_THCC_CNTNT` 세 필드에서 표기를 검색했다. 아래는 겹칠 수 있는 기관 수이며 모집·수강 자격의 확정값이 아니다.

| 신호 | 기관 수 | 해석 |
| --- | ---: | --- |
| 초등 | 15,194 | 초등 과정 표기. 초1 포함을 보장하지 않음 |
| 저학년 | 269 | 초저 후보. 유아·다른 문맥도 개별 검수 필요 |
| 초1 또는 초등1학년 | 154 | 명시적 학년 표기 후보. 초1~4 등 포함 |
| 1학년 | 84 | 중1·고1도 포함되어 단독 사용 불가 |
| 초급 | 5,567 | 난이도 표기. 학년 판정에 사용하지 않음 |

교습과정 목록만 읽으면 초등 12,214곳, 저학년 152곳, 초1 후보 100곳이다. 교습비 상세를 함께 읽으면 보완된다. 예: 교습과정 목록이 없는 기관도 `PSNBY_THCC_CNTNT`에 초등수학 등을 기재했다. 현재 기관 마스터와 지도 기관 JSON은 이 원문 필드를 내려주지 않는다.

재현 명령(앱 디렉터리):

```powershell
python etl/profile_academy_grade_evidence.py etl/runtime/academy/acainsti_scope_20261007.json docs/research/academy_grade_evidence_20261028.json
```

결과 JSON에는 입력 해시, 지역별·필드별 건수, 기관 키와 원문 예시를 보존했다. 정규식은 연구용 후보 추출이며 실제 정렬용 분류기는 아니다. 특히 붙여 쓴 `논술초1` 등은 누락될 수 있다.

## 셔틀 원천 확인

사용자가 기억한 두 출처는 '유아/아동 교육 관련 기관'과 '지자체'. 최근 채팅 목록과 저장소에서 과거의 정확한 두 URL은 복구하지 못했다. 아래는 이번에 별도로 찾아 공식 페이지로 확인한 원천/후보다.

1. [교육부_학교안전지원시스템_통학버스 등록현황](https://www.data.go.kr/data/15130628/fileData.do): 시설종류, 시설명, 소재지, 차량정보 등 개별 시설 정보를 제공한다고 명시. 기관 자체 다운로드 링크 방식이며 공공데이터포털의 '전체 행 1'을 실제 시설 한 곳으로 해석하면 안 된다. 포털 표시 파일명 기준일 2025-04-21, 수정일 2025-05-21, 갱신주기 수시. 실제 조회 결과 기준일과 수집 성공 여부는 별도 확인해야 한다.
2. [공식 통학버스 등록현황 조회](https://www.schoolsafe24.or.kr/front/scbus/scbusCmptncSchoolList.do?menuSn=170&upperMenuSn=146): 시도·관할청·시설명·학원/교습소 종류 검색 화면 확인. 이번에는 결과 파일 다운로드 및 NEIS 매칭률 검증까지 수행하지 않았다.
3. [서울시 구로구 유치원 통학차량 현황](https://data.seoul.go.kr/dataList/OA-20745/S/1/datasetView.do): 운행 여부·운행 및 신고 차량 수. 유치원알리미 재제공 자료. 표시 갱신일 2026-09-02. 유치원 대상이므로 학원·체육시설에 전용 불가. 사용자가 기억한 지자체 출처와 같은지는 미확정이다.
4. [교육부 통학버스 통계](https://www.data.go.kr/data/15130629/fileData.do)는 별개 데이터셋이다. 시도·관할청·시설종류별 집계라 개별 학원 정렬에 사용하지 않는다.

앞선 답변의 '공개 원천이 없으므로 학원 등록·부모 제보뿐'이라는 결론을 정정한다. 등록현황 원천이 있다. 다만 차량 등록은 선택 학교 픽업·초1 이용·현재 운행·시간대·빈자리·안전 인증을 뜻하지 않는다.

### 사용자 제공 상세 페이지 추가 확인

[통학버스 시설 상세](https://www.schoolsafe24.or.kr/front/scbus/scbusCmptncSchoolDetail.do)를 2026-10-28 확인했다. 같은 학교안전지원시스템의 상세 화면으로 보이며 별도 제공기관의 두 번째 독립 원천으로 세지 않는다. 시설명·시설구분·관할청·주소, 차량정보, 운영자·운전자·동승자 교육정보, 차량 상세의 보험·기관신고정보 영역이 HTML에 존재한다.

사용자가 제공한 URL의 `utm_source`는 유입 추적값이며 기관을 식별하지 않는다. 해당 값을 제거한 URL로 접근하면 시설값은 비어 있고 차량·교육정보에는 '조회된 데이터가 없습니다'가 표시된다. 따라서 확인한 것은 화면의 항목 구조이며, 특정 기관의 실제 값 공개 여부·조회 성공은 아직 검증하지 않았다. 목록에서 기관을 선택할 때 전달되는 식별값 또는 요청 정보를 확인해야 한다. 빈 화면을 미등록·미운행으로 해석하지 않는다. 서비스 정렬에는 시설 연결과 등록 여부·근거일을 우선 사용하며 상세 화면에 나타난 항목의 명칭만으로 안전 검증 완료 배지를 만들지 않는다.

## 권장 정렬과 연결 설계

사용자의 선택 분야·검색 조건을 적용한 목록 안에서 다음 순서로 검토한다.

1. 선택 학교 픽업과 초1 이용 가능이 확인된 기관.
2. 초1/저학년 과정이 확인된 기관과, 해당 아동의 이용 조건에 맞는 돌봄기관.
3. 통학차량 등록이 기관명+주소로 일치하는 기관. 표시 문구는 '통학차량 등록 확인'.
4. 초등 과정 표기가 있는 기관. 표시 문구는 '초등 과정 표기'.
5. 대상 정보가 없는 기관. 기존 거리순을 유지하며 숨기거나 '미운행'으로 판정하지 않음.

동일 단계에서는 기존 거리 기준을 사용한다. '거리순' 선택 시에는 순수 거리순을 보장한다. 정보가 없는 체육도장을 태권도라는 이유만으로 초1 확정 기관으로 올리지 않는다. 돌봄기관도 정원·지역·대상 조건을 확인해야 한다. 공부방은 NEIS 교습소로 포착되는 경우와 개인과외 등 미포착 경우가 있으므로 커버리지 차이를 남긴다.

후속 구현용 제안: 기관별 원문 근거와 `grade_evidence_level`, `shuttle_registration_status`(registered/unknown), 출처 URL·자료 기준일·확인일을 보존한다. 학교 픽업은 기관 속성이 아닌 기관-학교 연결 정보로 둔다. 이름만 일치하는 행은 자동 연결하지 않고 지역·정규화 주소까지 일치시킨다. 차량 수만큼 학원 행을 중복 생성하지 않는다. 등록이 조회되지 않으면 unknown으로 둔다.

기존 `neis:{교육청코드}-{지정번호}` / `dojo:{지자체코드}-{관리번호}`를 사용한다. 체육도장 원천 현재 필드에는 학년·셔틀 정보가 없다. 등록현황 수집 후 대표 지역에서 매칭률·동명이원·주소 이전 사례를 검수한 다음 serving 필드와 화면 정렬을 연결하는 순서가 적절하다.

## 검증 범위

전체 스냅샷으로 분석기를 실행하고 기관 키 유일성·표기 원문 예시·필드별 집계를 확인했다. 운영 수집/업로드·스키마·프런트엔드는 변경하지 않았다. 서비스의 우선순위 적용은 아직 완료되지 않았다.
