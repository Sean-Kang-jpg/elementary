# 1학년 과정 및 통학차량 등록 대조 결과

확인일: 2026-10-28. 로컬 기존 기관 원천과 학교안전지원시스템 공개 엑셀을 대조했다. 운영 DB의 현재 행이나 학교별 실제 화면 노출 기관 수를 조회한 결과는 아니다. 운영 DB·화면·정렬은 변경하지 않았다.

등록 원천 중 이름·지역·주소가 기존 명단과 연결되는 비율이다. 전체 학원 가운데 차량을 운영하는 비율을 뜻하지 않는다. 학원 등록 행 15건이 기존 기관 15곳에 각각 중복 연결되므로 등록 행 7,578건과 기관 7,563곳을 구분한다. 학원·교습소를 합친 고유 기관은 **7,670곳**이다.

기존 비교 명단은 직업기술 제외 학원 91,360곳, 교습소 43,244곳, 영업 중 체육도장 16,652곳, 다함께돌봄센터/키움센터 1,483곳이다. 이 가운데 이번 자료로 등록을 연결한 비율은 학원 8.28%, 교습소 0.25%다. 나머지는 미확인이며 미등록·미운행으로 단정하지 않는다.

- [학교안전지원시스템 통학버스 등록현황](https://www.schoolsafe24.or.kr/front/scbus/scbusCmptncSchoolList.do?menuSn=170&upperMenuSn=146)의 공식 엑셀 다운로드 양식을 사용했다. 로그인 없이 파일 수신에 성공했다.
- [교육부 공공데이터포털 안내](https://www.data.go.kr/data/15130628/fileData.do)와 연결되는 같은 원천이다. 별개의 독립 데이터로 중복 집계하지 않는다.
- 수신 파일은 `통학버스_관할지역별_기관_리스트_20261028212339.xlsx`(응답 파일명 기준)이며 1,455,486바이트다. 본문 기관 행 15,842건을 읽었다. 조회 화면을 먼저 확인한 시점에는 15,843건이었으나 다운로드 파일 시점의 건수를 분석 기준으로 삼았다.
- 전체 원본 분류: 학원 9,500, 유치원 3,591, 초등학교 2,261, 특수학교 183, 교습소 133, 중학교 94, 각종학교 39, 고등학교 30, 거점형늘봄센터 8, 유아교육진흥원 3.

- 기존 NEIS·체육도장·돌봄 스냅샷 파일명 기준일은 2026-10-07이다. NEIS 원문 `LOAD_DTM` 최댓값은 2026-10-04다. 이 날짜 차이로 신규·이전·명칭 변경이 불일치에 포함될 수 있다.
- 원본의 운영자명·차량번호는 결과 집계 및 연결 파일에서 제외했다. 원본과 기관별 상세 연결 결과는 Git에서 제외된 `etl/runtime/shuttle/`에만 보관한다. 별도 집계 JSON은 이 문서와 함께 보관한다.

## 연결 기준과 불일치

시설 종류와 시도가 같고, 정규화한 기관명과 주소가 함께 일치해야 연결한다. 공백·문장부호·법인 표기 및 시도 약칭을 정리한다. 도로명/지번 건물 번호를 포함한 주소를 비교하며 층·호 생략은 같은 이름+건물 후보가 유일할 때만 허용한다. 도로명·지번 간 변환, 임의 지오코딩, 유사 이름 자동 승격은 수행하지 않았다.

| 상태 | 학원 | 교습소 |
| --- | ---: | ---: |
| 기관명 정규화 + 주소 연결 | 7,385 | 98 |
| 학원/교습소 접미사 정리 + 주소 연결 | 193 | 9 |
| 이름은 있으나 주소 미확인 | 678 | 11 |
| 기관 후보 없음 | 1,241 | 15 |
| 같은 이름·건물에 기존 키가 여러 개 | 1 | 0 |

이름만 맞는 689행과 다중 후보 1행은 등록 확인으로 올리지 않았다. 지번/도로명 차이, 주소 이전, 기관명 변경·축약, 행정구역 표기 차이 등이 검수 대상이다. 같은 주소라도 이름이 다르면 자동 연결하지 않았다. 부동산 건물 거리나 학원 상호만으로 연결하지 않는다.

## 1학년 대상 교습과정

`LE_CRSE_LIST_NM`, `LE_CRSE_NM`, `PSNBY_THCC_CNTNT` 세 필드에서 학년 표기를 확인했다. `초1`, `초등1학년`, `초1~4`, 붙여 쓴 `논술초1` 등은 후보에 포함하고 `기초1`, `초급1`, `중등1학년`, `최초1회`는 제외한다. `초등수학1`은 1학년인지 반 번호인지 확실하지 않아 1학년 확정 후보로 쓰지 않는다. 현재 규칙은 누락이 있을 수 있는 연구용 후보 추출이다.

| 원문 신호 | 기존 기관 수 | 차량 등록도 연결된 기관 수 |
| --- | ---: | ---: |
| 초1/초등1학년 표기 후보 | 162 | 0 |
| 저학년 표기 | 269 | 1 |
| 초등 표기 | 15,194 | 16 |

위 세 행은 **겹칠 수 있다**. 상위 근거부터 하나씩 배정한 배타적 분류는 초1 후보 162, 저학년 268, 일반 초등 14,919, 학년 미상 119,255다. 모두 기존 NEIS 134,604기관 내 집계다. 앞선 탐색의 초1 후보 154곳보다 8곳 늘어난 것은 붙여 쓴 과목명+초1 표기 등을 추가로 인식했기 때문이다.

초1 후보의 기존 과목 태그는 수학 70, 영어 35, 국어·논술 35, 예능 16, 과학 2, 기타 외국어 2, 입시·종합 1, 기타 1이다. 이 태그는 기존 `academy_subjects.classify`의 이름·분야 기반 분류이며, 새로 확인한 것은 각 기관의 원문 학년 표기다. 교습비 내역 전체를 새 교과목 목록으로 확정한 것은 아니다.

**현재 스냅샷에서 학년 표기가 발견된 기관은 모두 교습소다.** 학원 91,360곳은 위 세 가지 학년 신호가 없다. 교습비 상세의 공백을 제외하면 실내용이 있는 학원은 1곳, 교습소는 28,383곳이다. 따라서 학원에 초1 수업이 없다고 해석해서는 안 된다.

| 원천 필드(공백 제외) | 학원 | 교습소 |
| --- | ---: | ---: |
| LE_CRSE_LIST_NM | 72,446 | 29,468 |
| LE_CRSE_NM | 78,625 | 35,117 |
| PSNBY_THCC_CNTNT | 1 | 28,383 |

현재 NEIS 원천만으로 학원의 대상 학년을 넓게 채울 수 없다. 학원 대상 학년 확장은 별도의 세부 과정 원천을 검증해야 한다. 차량 등록 신호는 학년 미상이어도 독립적으로 사용할 수 있다. 초1 표기와 차량 등록을 동시에 요구하면 이번 자동 연결에서는 0곳이므로, 사용자의 최초 의도대로 두 신호를 OR 조건으로 다룬다.

## 거점형늘봄센터와 체육시설

기존 돌봄 원천은 다함께돌봄센터 1,208곳과 우리동네키움센터 275곳이다. 교육청 거점형늘봄센터와는 다른 기관 종류다. 원본의 아래 8곳은 기존 돌봄 1,483곳과 기관명 및 주소를 종류와 무관하게 다시 비교해도 일치 후보가 없었다.

| 지역 | 차량 등록 원천의 기관명 |
| --- | --- |
| 경남 | 늘봄창녕 따숨 |
| 충북 | 충청북도교육청 제천 방과후돌봄센터 |
| 경남 | 경남교육청 돌봄센터 늘봄진주 |
| 인천 | 인천광역시교육청 동부 거점형 늘봄센터 |
| 인천 | 인천광역시교육청 남부 거점형 늘봄센터 |
| 서울 | 거점형늘봄센터 늘봄서울 |
| 인천 | 인천광역시교육청 서부 거점형 늘봄센터 |
| 전남 | 목포교육지원청 거점형늘봄센터 늘봄목포 |

별도 기관 명단을 추가해야 하는 공백이며, 0% 일치로 표시하지 않는다. 이 8곳을 거점형늘봄센터 전체 명단으로 간주하지도 않는다.

기존 체육시설 레이어의 이번 비교 대상은 영업 중 체육도장 16,652곳이다. 수영장 등 모든 체육시설을 포괄하지 않는다. 확보한 학교안전지원시스템 원본에는 체육시설 유형이 없으므로 차량 등록 일치율은 산출할 수 없다. 추가 공개 원천 검색에서도 이번 대조에 투입할 체육시설별 전국 등록 명단은 확보하지 못했다. 이 상태를 미등록으로 내려주지 않는다.

