# 시간표 카드 내 일정 선택

Date: 2026-10-18. Deployment result will be recorded under docs/operations/.

## User flow

`하루/주간 시간표에서 추가 → 선택 요일의 카드 → 방과후·돌봄 / 외부 학원 / 직접 입력`

- 학교 프로그램은 원천 운영 요일에 선택 요일이 포함된 반만 표시한다. 요일 미확인 반은 요일별 목록에서 제외하고 안내한다. 전체 선택 메뉴는 보조 경로로 남긴다.
- 카드는 원천 시간을 유지하며 **선택한 요일만** 추가/해제한다. 동일 반의 다른 선택 요일·신청 상태·출처를 덮어쓰지 않는다. 저장 시 최신 로컬 저장소를 읽는다.
- 돌봄·방과후·맞춤형은 독립 선택한다. 오후·연장 돌봄의 이용 요일을 사용자가 명시 선택하며 이용 자격·복귀 가능 여부를 확정하지 않는다.
- 아침돌봄은 기존 공개 시간 자료가 있을 때 선택 요일에 넣는다. 미확인 시간/운영 여부를 추측하지 않는다.
- 외부 학원은 **선택 학교의 배정 아파트 생활권(가까운 배정 아파트 기준 직선거리 800m)**의 기존 공개 RPC를 재사용한다. 학교 건물과의 거리가 아님을 표시한다. 분야는 기존 상호명/realm 분류를 재사용한다. 같은 주소의 다른 분야 학원을 섞지 않고 개별 학원 단위로 필터링한다.
- 목록의 학원을 고르면 수업 시간은 빈칸으로 시작한다. 사용자가 확인한 5분 단위 시간을 입력하면 편집 가능한 개인 후보 일정으로 저장한다. 학원 선택이 신청·수강·운영 요일 확인을 의미하지 않는다.
- 데이터는 브라우저 시간표 저장소에만 저장한다. DB schema/API/migrations/환경변수/배포 설정은 바꾸지 않는다. 테스트 픽스처는 localhost에서만 사용한다.
