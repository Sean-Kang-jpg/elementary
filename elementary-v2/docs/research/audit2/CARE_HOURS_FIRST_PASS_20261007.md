# 학교 돌봄 운영 시간 — 1차 검수 (A2-R02)

2026-10-07. 출처는 학교알리미 15-라 2026년 5월 공시 첨부(60/60). 1차 검수는 assistant가 했고 **사용자 확인 전**이다. 게시 승인은 아직 없다(`not_approved`).

- 자동 탐지: `python -m etl.audit_schoolinfo_care_plans` → [탐지 결과](schoolinfo_care_plan_audit_20261007.json). 돌봄·늘봄이 들어간 줄의 시각만 모았다. 탐지 43/60. 방과후 프로그램 종료 시각(16:00~16:30)이 섞여 최빈값을 그대로 쓸 수 없었다.
- 1차 검수: 원문 창을 읽었다. 제목과 시간이 다른 줄로 나뉜 문서는 줄을 합친 텍스트에서 다시 찾았다. 결과는 [검수 값](care_review_first_pass_20261007.json)이며 학교별 근거 문구를 붙였다.
- 첨부는 모두 읽을 수 있었다. 자료가 없는 16곳은 공시 첨부가 방과후 프로그램 계획뿐이거나 돌봄 시간을 적지 않은 경우다.

- **"17시 기본 + 저녁돌봄 19~20시"형과 "처음부터 19시까지"형이 반반**이다. 부산·서울은 앞의 형, 경기·인천은 뒤의 형이 많다. 카드에 종료 시각 하나만 쓰면 부모가 오해한다.
- 저녁돌봄·연장반은 "희망자 있을 시", "수요 시", "특정 반만" 같은 조건이 붙는다. 기본 운영과 구분해서 표시해야 한다.
- 대상 학년은 대부분 1~2학년이지만 1~3·1~4·1~5학년도 있다. 모든 학교가 정원과 선발 순위(저소득·한부모·맞벌이)를 둔다. 공시 시간이 곧 "우리 아이가 이용할 수 있는 시간"은 아니다.
- 돌봄 시간이 없는 16곳: 금사·판교·안말·성남송현·초림·판교대장·오리·인천구월·청산·영광중앙·가거도·소라남분교·일로동·서울신도·서울거여·서울조원. 이전 결정에 따라 `학교 확인 필요`로 표시한다.
- 학교알리미 정형 수치(SQL 23 `school_care_statistics`)는 저녁돌봄 교실 수까지 주지만 운영 시간은 없다. 저녁돌봄 운영 여부를 교차 확인하는 용도로만 쓴다.
