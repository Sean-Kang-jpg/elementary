# MY 시간표: 5분 단위 직접 조작과 파스텔 카드

## 디자인

첨부 1의 주간 시간 그리드에 첨부 2의 둥근 파스텔 카드와 작은 종목 아이콘을 결합했다. 첨부 3의 세로 목록은 여러 요일 비교에 맞지 않아 기본 보기로 사용하지 않았다.

- 왼쪽 12:00~19:00 공통 시간축과 월~금 가로 열을 유지한다. 모바일은 내부 가로 스크롤과 요일 바로가기를 함께 제공한다.
- 정규수업 블루그레이, 돌봄 라벤더, 맞춤형 민트, 방과후 살구, 개인 일정 핑크로 구별한다. 선택 테두리도 보라색으로 맞췄다.
- 카드 첫 줄은 단순한 과목 분야 SVG 아이콘과 ‘종류 · 프로그램명’, 둘째 줄은 시각이다. 후속 사용자 요청에 따라 이모지와 복잡한 일러스트는 사용하지 않고 기존 Lucide 선형 아이콘 체계를 재사용한다. 미술 팔레트·음악 음표·체육 공·과학 플라스크·코딩 노트북·독서 책·수학 계산기 등으로 구별한다. 장식 아이콘은 접근성 이름과 저장된 프로그램 이름을 바꾸지 않는다.
- 카드의 왼쪽 색상 강조선과 장식 테두리를 제거했다. 종류 구분은 파스텔 면색만 사용하며, 선택·키보드 초점 테두리는 조작 피드백으로 유지한다. 후보도 점선 테두리 대신 연한 면색으로 표시한다.
- 짧거나 겹쳐 이름이 잘리는 카드는 눌러 전체 시각·이름을 확인한다. 학교 자료의 시각은 반올림하지 않는다.

## 직접 조작

- 빈칸 클릭/탭: 5분 단위로 시작 시각을 맞춘 일정 추가 창을 연다. 기본 길이는 1시간이며 19시 경계에서는 줄인다.
- 마우스로 빈칸 드래그: 선택 구간을 5분 단위로 미리 보여 주고 이름·유형·요일·시간을 확인한 뒤 저장한다. 역방향 선택도 가능하다.
- 직접 입력한 카드 드래그: 시간과 요일을 바꾼다. 기존 길이·참여 상태는 유지한다. 여러 요일에 반복되는 일정은 잡은 요일만 분리하고 다른 요일은 그대로 둔다.
- 학교 자료에서 가져온 정규수업·강좌·돌봄은 직접 이동할 수 없다. 자료와 사용자 입력을 혼동하지 않도록 출처가 있는 일정은 보호한다.
- 모바일 빈칸 드래그는 스크롤로 처리하고 의도치 않게 일정을 만들지 않는다. 직접 입력한 카드는 터치로 옮길 수 있다. 카드 이동 중 가로 스크롤·스냅을 잠그고 종료·취소·포커스 해제 시 복구한다.
- 키보드: 시간 열에 초점을 두고 위·아래 화살표로 5분 이동, Enter/Space로 추가, Escape로 취소한다. 기존 카드 상세의 ‘요일·시간 수정’으로도 편집할 수 있다.
- 직접 추가는 후보 상태로 저장한다. 신청·참여 확정을 자동으로 바꾸지 않는다. 저장 실패·다른 탭의 최신 수정·자료 보호 검사에 걸리면 원래 계획을 그대로 유지한다.

## 검증

- `npm run lint`, `npm run typecheck`, `npm run build`(사이트맵 포함), 단위 검사 68개 통과.
- `my-calendar-edit-smoke.mjs`: 실제 마우스로 클릭·정방향/역방향 드래그 생성, 5분 정렬, 요일 간 이동, 반복 요일 분리, 길이·신청 상태 보존, 범위 밖 드롭 취소, 출처 일정 보호, 키보드, 새로고침, 모바일 폼, 잘못된 시각 거부, 저장 실패 유지 및 두 줄 아이콘 카드를 검증했다. Windows의 agent-browser 시간 입력 이벤트 차이는 검사 도구에서 보완했다.
- `my-calendar-touch-smoke.mjs`: 별도 모바일 브라우저의 실제 터치 이벤트로 탭 생성, 기본 시간 입력, 요일 변경, 가로 스크롤 중 오생성 방지, 카드 이동의 요일·길이 보존, 화면 넘침 및 런타임 오류 없음을 확인했다. Playwright는 설치된 패키지 또는 `CALENDAR_QA_PLAYWRIGHT` 경로를 사용할 수 있으며 브라우저 경로는 `CALENDAR_QA_CHROME`으로 지정한다. 앱 의존성은 추가하지 않았다.
- 기존 `my-ux-smoke.mjs` 통과: 초안·내 시간표·관심 학교 전환·저장 실패·실제 학교 조회를 유지한다.
- `my-schedule-smoke.mjs` 통과: 반별 선택·해제·돌봄 동시 선택·연계 안내·두 줄 아이콘·조회 및 저장 실패·다섯 화면 너비를 검증했다. 10월 14일 기록과 달리 이번 실행에서는 실제 서울대현초 강좌 공개 조회가 성공하여, 강좌 선택·원천 요일/시간 자동 입력·DB 출처 보존과 실제 돌봄 조회·선택까지 확인했다. 이 작업이 데이터를 배포한 것은 아니다.
- 공개 전체 검사에서 주소 origin·공유 메타데이터·앱 진입·지역 데이터 단계는 통과했지만, 지도 축소 후 시도 마커 전환 대기가 실패했다. 전체 공개 게이트는 미통과이며 이번 범위에서 지도 코드를 변경하지 않았다.

화면 캡처는 격리된 검사용 일정이다. 실제 학교 운영계획이나 신청 결과를 의미하지 않는다. 이번 작업에서 운영 데이터 적재·DB 변경·배포·커밋은 하지 않았다.

실행 예:

node scripts/my-calendar-touch-smoke.mjs http://localhost:3012 <터치 캡처.png>
node scripts/my-schedule-smoke.mjs http://localhost:3012

## 단순 과목 아이콘 후속 검증

- 타입 검사·사이트맵 포함 빌드·단위 검사 73개 통과. 변경한 시간표 TS/TSX 파일의 ESLint 검사 통과.
- 전체 lint는 별도 변경 중인 `src/utils/homeShelves.ts:49`의 미사용 `_index` 오류로 미통과했다. 시간표 작업에서 해당 홈 파일은 수정하지 않았다.
- `my-calendar-appearance-smoke.mjs`로 360/390/768/1280px에서 이모지 없는 SVG·두 줄 구조·모든 방향 장식 테두리 제거·화면 넘침 없음·과목 선택 버튼 동작·브라우저 런타임 오류 없음을 검증했다.
- `my-calendar-touch-smoke.mjs`에서 터치 탭 생성·5분 입력·요일 변경·가로 스크롤 중 오생성 방지·터치 카드 이동을 다시 확인했다.
- 최신 디자인은 `my-calendar-simple-icons-20261015.png`와 `my-calendar-simple-icons-20261015-mobile.png`에 기록했다. 이전 이모지 캡처는 변경 이력이다. 생성했던 복잡한 일러스트 시안은 채택하지 않았으며 앱 자산으로 연결하지 않았다.
- 후속 공개 전체 검사는 처음에는 종료된 서버의 연결 거부로 실패했다. 서버를 다시 연 후에도 3013의 `/`와 `/@vite/client`가 제한 시간 안에 응답하지 않아 공개 검사를 완료하지 못했다. 3012의 최종 빌드 미리보기에서는 디자인·과목 선택·터치 검증이 모두 통과했다. 전체 공개 게이트 통과로 보고하지 않는다.
