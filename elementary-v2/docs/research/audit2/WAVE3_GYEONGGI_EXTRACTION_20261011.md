# E05 3차 확대: 경기(성남 제외) (2026-10-11)

대상은 경기 30개 시·군 **1,306곳**이다. 성남은 2026-10-08에 이미 반영했다. 방식은 2차(서울)와 같다.
- 수집은 스크립트가 했다.
- 추출은 소네트 하위 에이전트가 했다. 26곳씩 51배치였다.
- 사람이 원문을 본 것은 검증에 실패한 항목과 표본뿐이다.

**사용자 확인 전**이며, 적재기는 확인 전에 `--apply`를 거부한다.

검증기가 새로 받아들이게 된 원문 표기는 네 가지다.
- 12시간제 오후 시각: "1:30"은 13:30, "01:00"은 13:00으로 읽는다.
- 숫자 사이 공백: "1 2:1 0".
- 텍스트에 섞인 NUL 문자.
- 쌍점 대신 쌍반점: "19;00".

이렇게 고친 검증기로 1차 정답(208곳)을 다시 채점했다. 자동 승인 98.2%, 승인분 정확도 99.1%로 바뀌지 않았다.

제외한 11곳 가운데 5곳은 카드 형식으로 나타낼 수 없는 구조다. 1·2학년이 5교시를 마친 뒤 점심을 먹거나, 4·5교시를 블록으로 묶은 뒤 점심을 먹는다. 나머지는 점심 시각이 표에 없거나, 모델이 원문에 없는 값을 계산해 넣은 경우다.
