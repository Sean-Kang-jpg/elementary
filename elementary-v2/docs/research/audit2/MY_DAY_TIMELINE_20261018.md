# MY 하루 시간표 — 참고 시안 2 반영

Date: 2026-10-18. 최신 배포 결과는 docs/operations/의 해당 날짜 릴리스 기록을 따른다.

## 화면

- 사용자 첨부 `codex-clipboard-573d0c4e-e02c-4773-8b27-1f6edcd423fb.png`의 가운데 일일 시간표를 기본 보기로 채택했다.
- 상단 요일 선택, 검은색 세로 캡슐 선택 표시, 왼쪽 시작/종료 시각과 가는 타임라인, 넉넉한 둥근 파스텔 카드로 구성했다. 실제 날짜가 아닌 반복 시간표이므로 임의의 날짜·진행률을 표시하지 않는다.
- 카드 본문은 종류·프로그램명 / 시간의 두 줄이다. 기존 Lucide 분야 SVG를 카드 오른쪽에 옅은 큰 아이콘으로 배치했다. 이미지 생성·이모지·카드 왼쪽 색상 테두리는 사용하지 않는다.
- 아침돌봄은 선택된 요일에만 맨 앞에 표시한다. 정규수업은 작은 카드로 축약하고 예상 하교만 표시한다. 엔진 내부의 가정 등교시각을 노출하지 않는다.
- 미확인 시간을 만들지 않는다. 미확인 아침돌봄은 등교 전, 다른 미확인 일정은 마지막에 표시한다. 취소·미선정·방학 전용 일정은 학기 중 하루 보기에 표시하지 않는다.
- 돌봄·방과후/맞춤형 동시 선택은 유지하고 복귀 연결 안내를 별도로 표시한다. 순서·카드 높이는 실제 수업 길이나 이동 가능 여부를 뜻하지 않는다.

## 편집과 데이터 경계

- `하루 보기`는 읽기 중심이며 카드 선택으로 기존 상세·직접 일정 편집을 연다. 추가 버튼은 선택한 요일의 카드 내 선택(학교 프로그램 / 외부 학원 / 5분 직접 입력)을 연다.
- `주간 편집`으로 기존 12–19시 그리드·클릭 생성·드래그 이동·키보드 입력을 유지한다. 모바일에서 두 보기를 바꿔도 선택한 요일로 스크롤한다.
- 원천 강좌/돌봄은 직접 이동·수정하지 않고 기존 선택 메뉴에서 관리한다.
- 스키마·API·저장 포맷·운영 데이터는 변경하지 않았다. 검사용 일정은 격리된 로컬 브라우저 저장소에만 넣는다.
