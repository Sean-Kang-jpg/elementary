# 파일럿 확대 1차 검수 — 성남시 + 서울 강남·서초·송파 (2026-10-08)

사용자 결정(2026-10-08)으로 "초1 하루 예상" 범위를 넓혔다. 대상은 170곳이며, 기존 파일럿과 겹치는 22곳을 뺀 **새 학교 148곳**을 검수했다. 1차 검수는 assistant가 했고 **사용자 확인 전**이다. 적재기는 확인 전 `--apply`를 거부한다.

## 결과

- **요일별 예상 하교: 71곳 완성.** 시정표가 탐지된 74곳 중 3곳(서울원명·대치·청담)은 행사 일정표뿐이라 제외했다.
- **1학년 점심이 4교시보다 먼저인 학교가 26곳(37%)**이다. 기존 파일럿은 35곳 중 4곳이었다. 위례 신도시와 송파·강남·서초에 많고, 이 학교들은 4교시 날 4교시가 끝나면 하교한다.
- 첫 교시가 09:10에 시작하는 학교(보평·불정)와 08:50에 시작하는 학교(아주·대현·도성·일원 등)가 있어, 하교 시각 범위가 12:40~13:50으로 넓다.
- 시정표가 없는 74곳은 카드에 돌봄 부분만 나오거나, 돌봄도 없으면 카드가 나오지 않는다.
- **돌봄 시간 확인 55곳**, 시간 미기재 93곳은 `학교 확인 필요`다. 서울은 "오후 ~17:00 + 저녁 17~19시"형, 성남은 "~18:00/19:00까지"형이 많다.

## 사용자 확인 요청

1. **NEIS와 문서의 교시 수 충돌 1곳**: 분당초 수요일(NEIS 5 / 문서 4). 기존 결정대로 NEIS를 따랐다.
2. **medium 신뢰도 시정 5곳**: 단대(5교시가 "방과후 활동"으로 표기), 희망대·삼릉(합쳐진 PDF 열), 언북(1·2학년 열 추정), 개포(1,2,5학년 점심 행 해석).
3. **돌봄 해석 4곳**
   - 서울신중: "오후 13:40~19:00"과 "정규수업 후~17:00, 저녁 17:00~22:00(수요 시)"가 함께 적혀 있다. 17:00 + 22:00(수요 시)로 적었다.
   - 대하: "방과후~18:00"과 "최소 1실 19시"가 함께 있다. 18:00 + 19:00(최소 1실)로 적었다.
   - 서울대진: "오전+오후 08:00~17:00"을 오후 종료 17:00으로 적었다.
   - 서울대곡: 저녁 시간을 전담사 근무 행에서 읽었다.
4. **기본 종료 없이 연장만 적힌 6곳**(가락·송전·잠현·영풍·원촌·송례)은 기본 시간을 추정하지 않고 `학교 확인 필요`로 두었다.

확인 후에는 적재기의 확대 세트를 `confirmed`로 바꾸고 `--apply`하면 된다. 화면 코드는 바꿀 필요가 없다. 운영 반영 뒤 카드가 보이는 학교는 106곳(하교 예상)이고, 돌봄 행은 208곳이다.
