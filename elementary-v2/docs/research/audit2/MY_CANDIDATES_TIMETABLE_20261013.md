# MY 후보·시간표 개편

## 범위와 구조

기존 단일 지도와 공시 조회 경로를 재사용한다. DB·로그인·수집 배치를 변경하지 않는다.

1. MY 최상단 입학연도 선택 또는 저장된 연도 요약. ‘입학 준비 설정’ 별도 제목은 제거하며 접근성 영역 이름 ‘입학연도’는 유지
2. 입학 체크리스트 배너
3. 우리 아이 시간표: 학교별 초안 선택 / 하나의 ‘내 시간표’ / 주간 일정 / 참여 상태 관리
4. 관심 후보: 학교·아파트 분리, 각각 신규 저장 최대 3곳
5. 기존 로드맵·기기 내 저장 안내 유지. MY의 입학 준비 가이드 배너는 제거하며 GNB의 입학 준비 진입과 기존 가이드 URL은 유지

관심 학교 제거는 시간표 제거가 아니다. 별도 초안 삭제를 확인해야 제거된다.
기존 3곳 초과 즐겨찾기는 강제로 잘라내지 않는다. 아파트 저장은 학교 저장이나 시간표 선택으로 이어지지 않는다.
아파트 배정 학교를 관심 학교로 저장하는 동작은 명시적이고 멱등이다.
배치 재빌드로 단지 내부 ID가 바뀌어도 공개 키가 같은 즐겨찾기는 두 칸을 쓰지 않는다.

## 상태와 데이터 규칙

- localStorage: 기존 elementary-favorites-v1 유지, 시간표는 elementary-schedule-plans-v1 별도 버전 저장.
- 기본 시간표 선택은 한 개이며 전환·해제할 수 있다. 다른 초안은 유지한다.
- 참여 상태(후보/계획 포함/신청 중/참여 확정/미선정/취소)는 시간표 선택과 독립이다.
- 운영 시간 자료는 원본의 학년도·자료판·검토일·대상 입학연도를 남긴다.
- 하교는 예상, 시간 NULL은 미확인. 자료 없는 학교에는 시간을 생성하지 않는다.
- MY 자료 가져오기는 개발용 대체 자료를 사용하지 않는다. 조회 실패는 재시도 또는 명시적 빈 초안 생성으로 처리한다.
- 운영 돌봄 시간은 이용 가능·1학년 대상·입소 확정을 뜻하지 않는다. 이동/인계 규칙도 미확인으로 가져온다.
- 직접 입력한 일정은 후보로 시작하며 근거 확인 상태와 실제 참여 상태를 합치지 않는다.
- 기기 내 저장 실패 시 성공으로 표시하지 않고 기존 저장 내용을 유지한다. 여러 탭 변경 구독은 해제한다.
- 관심 후보 상세는 펼칠 때만 읽는다. 학교·교육환경의 독립 조회는 병렬 처리하며 일부 실패를 별도로 표시한다.
- 기존 학구·아파트·학교 URL과 전국 QA 게이트를 유지한다.

## 로컬 QA

- lint / typecheck / 전체 빌드 / 사이트맵 생성 통과
- 단위 테스트: 시간표 엔진·프로필 관련 기존 테스트와 후보/시간표 저장 테스트 포함
- public-smoke: localhost:3001의 실제 지도 SDK, 지역 마커, 검색·배정·딥링크, MY, 가이드, 체크리스트 회귀 통과
- my-ux-smoke: 격리된 브라우저 저장 테스트 자료로 초안 비교·선택·복원·삭제 분리·저장 공간 실패·모바일/데스크톱 레이아웃 검사
- 같은 MY 검사에서 실제 서울대현초 상세 저장 → MY 공시/교육환경 읽기 → 운영 자료 가져오기 경로 확인
- p1-ux-smoke: 4개 지도 영역, 종속 조건, 공통 시트·출처/NULL/0 표시 회귀 통과. 실제 표본의 센터 목록은 비어 있어 센터 상세는 명시된 개발 전용 테스트 자료로 검사

초기 빌드는 공유 의존성 경로 쓰기 권한으로 실패해 승인된 실행으로 재검증했다.
초기 브라우저 게이트는 빌드 생성 중의 미완성 dist를 읽어 실패했으며, 완료 후 실제 지도 전체 검사가 통과했다.
배포 확인은 정확한 Git 커밋의 Vercel READY와 운영 URL의 별도 회귀 결과로 기록한다.

## 학교 상세 입학 안내 간소화

- ‘이 학교 입학을 준비한다면’은 입학연도 미선택 시 두 단계의 첫 가이드만 보여 준다. 공립은 ‘취학통지서’와 ‘이사 시점’ 안내이며 두 번째 가이드 링크는 이 슬롯에서 제거한다. 가이드 자체와 URL은 삭제하지 않는다.
- MY에서 연도를 선택하면 앱의 동일한 entryYear를 학교 상세에 전달해 stageOf 기준의 해당 단계 첫 가이드 한 개만 표시한다. 기존 기준(입학 전해 9월부터 admission)을 변경하지 않으며 별도 저장값·구독·DB 조회를 만들지 않는다.
- 국립·사립의 admission 첫 가이드인 private-national은 유지한다. 원래 상세 시즌 순서와 수정 키를 사용한 링크 열기도 보존한다.
- lint / typecheck / 전체 빌드 / 단위 테스트 40개 통과. 흥인초 실제 상세의 미선택·MY 세 가지 연도 변경·페이지 재진입·가이드 이동/뒤로 가기·모바일/데스크톱 검사 통과.
- 공개 회귀 게이트는 기존 ‘4개 이상’ 검사를 ‘단계별 첫 항목 총 2개’로 갱신하며, 학구·배정·SEO와 다른 데이터 게이트는 유지한다.

## 배정 아파트 목록 헤더 간소화

- 제목 바로 옆에 단지 수를 4px 간격으로 배치하고 우측 한 줄 정렬 메뉴로 구성한다. 별도 정렬 버튼 행은 제거한다.
- 모바일 폭에서 네 버튼을 억지로 배치하지 않고 기본 select로 4가지 정렬 기준 × 오름/내림차순 8개 선택지를 제공한다. 기본 세대수 내림차순, 기존 정렬 비교 방식·로딩·오류·빈 결과·단지 상세 이동은 유지한다.
- select에는 ‘단지 정렬’ 접근성 이름과 44px 터치 높이를 제공한다. 목록 조회·배정 데이터·NULL/0 처리·원천 자료·지도 필터는 수정하지 않는다.
- 실제 흥인초·대현초의 360/390/430/1280px에서 제목·단지 수·정렬의 동일 행, 겹침/가로 넘침 없음, 헤더 75px 미만을 확인했다. 대현초 실제 단지의 8가지 정렬 및 상세 진입 검사 통과.
- lint / typecheck / 전체 빌드 / 단위 테스트 40개 통과. 배포 결과와 운영 회귀 검사는 별도 배포 기록에 남긴다.

## 아파트 정보형 아이콘

- 카드·상세의 공통 SVG를 부드러운 모서리·단순한 창문·은은한 면색의 64×64px 아이콘으로 변경한다. 기존 68×76px 배치보다 빈 공간을 줄인다.
- 세대수 밀도 기호는 기존 300/1000/3000세대 경계에 따른 1/2/3/4개 실루엣을 유지한다. 실제 동 수는 기존 본문에서 표시하며 실루엣은 실제 외관이나 동 수가 아니다.
- 연식은 10년 이하 세이지 / 11~25년 블루그레이 / 26년 이상 웜샌드, 미확인 중립 회색으로 구분한다. 같은 규모의 실루엣 높이·지붕은 모든 연식에서 동일하다.
- 연식 배지와 아이콘은 공통 표현 함수·팔레트를 사용한다. 기존 양수 serving age 우선과 유효 준공연도 대체 계산은 유지하고, 자료 없는 0은 미확인, 유효한 올해 준공연도의 0년은 신축으로 구분한다. DB 쓰기·별도 조회·저장·구독은 추가하지 않는다.
- 단위 검사에는 연식·규모 경계값·미확인·올해 준공과 배지 글자 대비(4.5 이상)를 추가한다. 개발 전용 화면 QA는 16개 조합과 미확인 카드를 실제 공통 컴포넌트로 검사한다. 표본은 운영 데이터가 아니며 빌드 진입점에 포함하지 않는다.
- 지도 마커·80명 기준·지도 데이터 의미는 이번 아파트 아이콘 변경 범위가 아니다. 운영 결과는 별도 배포 기록에 남긴다.

## 미해결·후속 범위

- 방과후/1학년 과목 분류의 DB 업데이트·정확성·운영 배포 QA는 기존 담당 작업이다. 중복 개발하지 않는다.
- 강좌 일괄 가져오기/직접 신청, 다른 기기 동기화, 복수 자녀, 방학·날짜별 예외 편집은 이번 범위가 아니다.
- 학교별 초안은 학기 중 주간 계획이며 운영 자료 갱신이 사용자 일정을 자동 덮어쓰지 않는다.
- 아파트에는 기존 대표 배정 정보를 표시하며 공동학구·조건별 배정은 기존 상세에서 확인한다. 신규 배정 판정은 하지 않는다.
- P0 전국 원본 공시 대조, 공시 기준일·유형별 비율 분모 확인, 방과후 연계형 1학년 대상 수동 검수는 기존 Audit의 미해결 항목이다.
- 센터 모집/예약/여석은 자동 확정하지 않는다. 전국 운영 정보가 이번 UX 배포로 검수 완료되는 것은 아니다.
