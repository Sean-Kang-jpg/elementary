## 실행한 검증

```powershell
python -m etl.build_morning_care_research
python -m unittest etl.tests.test_morning_care_research etl.tests.test_schoolinfo_care_plans etl.tests.test_collect_care_data
```

연구 빌더는 원문 72개를 검증하고 40개 결과를 다시 만들었다. Python 테스트 **15개 통과**.
새 테스트는 실제 표본의 미기재/계획/시각충돌/수업전/방학미운영/현황인원 사례와 인명 마스킹 시각 훼손 회귀를 확인한다.
`git diff --check`도 통과했다. 프론트 변경은 이 트랙에서 하지 않아 프론트 빌드·브라우저 테스트는 이 조사 검증 범위가 아니다.
