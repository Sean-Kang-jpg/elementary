# 학년 안내의 상·하위 문맥 재검토

2026-10-19. 원문 위·아래, 동일 표의 병합 학년 셀, 별도 프로그램 제목과 방학 구분을 재검토했다.
운영 DB는 변경하지 않았고 연구 데이터만 수정했다.

## 직접 근거 복구

첫 추출의 학년 미확인 460행 중 25행은 학년 안내가 없는 것이 아니라 아래 줄·왼쪽 셀·병합 머리글 연결을
놓친 경우였다. 해당 값을 복구해 미확인은 435행으로 줄었다. 복구한 25행 중 초1 포함은 17행, 초1 비대상은 8행이다.

| 학교 | 복구 행 | 근거 |
|---|---:|---|
| 경희초 | 5 | 바로 다음 줄의 학년 또는 같은 행의 학년 셀. 코딩의 ‘2개 학년’은 어느 학년인지 불명확해 그대로 미확인 |
| 은석초 | 7 | 영어 Global Class 표의 1·2학년 / 3·4학년 / 5·6학년 병합 대상 셀 |
| 동광초 | 3 | 중국어·PBL·1인 1악기의 같은 행 또는 바로 이어진 학년 셀 |
| 운현초 | 4 | 같은 표 안에서 병합된 독서·기초한글 대상 학년 |
| 유석초 | 6 | 서양악·국악 및 영어 프로그램의 행별 학년 안내 |

각 수정값의 원문 해시·줄 번호·판정은 [grade_context_review.json](grade_context_review.json)에 기록했다.

## 전 학년 문구가 있어도 범위를 구분할 사례

| 학교 | 확인 문구 및 위치 | 적용 판단 |
|---|---|---|
| 은석초 | L24 ‘대상: 1~6학년 중 희망 학생’ | 방과후 전체 신청 대상 안내. 개별 영어 분반은 표의 학년 셀을 우선 적용 |
| 한신초 | L13·L24 선택형 교육 프로그램 ‘1~6학년 중 희망 학생’ | 학교 전체 대상 정보로 보존. 모든 분반에 초1이 참여 가능하다고 확정하지 않음 |
| 이대부초 | L75·L81 ‘1~6학년’ | 운영기간의 학년 범위. 개별 강좌 학년으로 사용하지 않음 |
| 매원초 | L135 ‘1～6학년을 대상으로 수업을 운영한다’ | L111 이후의 특성화 영어교육 운영 원칙. 앞쪽 일반 방과후 강좌 32행에 적용하지 않음 |
| 상명대부초 | L259 ‘원어민과 함께하는 영어캠프 (1∼6학년)’ | 방학 영어캠프 대상. 학기 중 발레·난타 등에 적용하지 않음 |
| 유석초 | L467 등 전 학년 공통 안전귀가 매뉴얼 | 안전관리 적용 범위이며 강좌 수강 대상이 아님 |
| 성신초·한양초 | 모집 안내 표의 ‘전교생’ | 안내를 받는 대상. 개별 강좌 학년 근거가 아님 |

표 전체·해당 프로그램 전체에 적용되는 학년 머리글은 직접 근거가 될 수 있다.
반면 학교 전체 모집 범위, 다른 프로그램, 방학 안내와 홍보 수신 대상을 개별 반의 학년으로 바꾸지 않는다.
상위 안내는 별도 grade_scope_guidance로 보존해 정보 자체를 버리지 않는다.

## 검증

관련 Python 테스트 22개 통과. 병합 대상 근거 줄 보존과 별도 영어 프로그램의 학년이 일반 강좌로 전파되지 않는
회귀 검사를 포함한다. 원본을 새로 내려받거나 현재 개설·신청 가능 여부를 확인한 검사는 아니다.
