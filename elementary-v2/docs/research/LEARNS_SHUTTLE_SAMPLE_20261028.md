# 런즈 셔틀 정보와 공식 등록자료의 공개 표본 비교

확인일: 2026-10-28. 공개 웹페이지에서 확인한 최소 항목을 기존 로컬 원천과 대조한 탐색 조사다. 로그인·회원정보·비공개 API를 이용하지 않았다. 런즈 원문 설명·리뷰·사진을 복제하거나 운영 DB에 넣지 않았다.

## 결론

런즈는 공식 등록 명단이 제공하지 못한 셔틀 표기를 보완할 후보 원천이다. 표본 중 기존 NEIS 기관과 이름·주소가 일치하는 **수학의힘 외대HS2관학원**, **브레인리그운정학원**은 런즈에 셔틀 있음이 표시되지만 확보한 공식 등록자료에서는 이름+주소가 연결되지 않았다. 런즈가 정확하거나 최신이라는 결론은 아니며, 추가 확인 대상을 발굴한 것이다.

이번 8곳은 런즈 홈의 파주 운정 수학·서울 중계 미술 노출 목록과 그 공개 페이지에서 연결된 수영장 중 접근 가능한 곳을 고른 편의표본이다. 무작위 지역 표본, 전국 커버리지 측정, 정확도 검증이 아니다. 접근 실패한 시매쓰 운정센터와 국가대표 경희대 부부 태권도장은 미확인으로 제외했다. 아래 결과로 전체 일치율을 계산하지 않는다.

## 런즈에서 더 확인할 가치가 있는 정보

1. 공식 등록 연결이 안 된 기존 기관의 셔틀 유무 표기. 두 학원처럼 추가 확인 후보를 찾을 수 있다.
2. 수영장 등 현재 공식 등록 원천 밖의 기관. 다만 기존 어디초 체육 레이어도 체육도장 중심이므로 셔틀뿐 아니라 기관 명단 보강이 필요하다.
3. 수업대상·초등 저학년 과정. 현재 NEIS 학원의 학년 정보 공백을 보완할 후보지만, '초등' 표기만으로 초1 수강 가능을 확정하지 않는다. 학부모 리뷰나 비용 공유 내역은 별도의 출처다.
4. 브랜드명·지점명과 등록명의 별칭. 주소만 연결할 때 생기는 같은 건물의 다른 학원 오연결을 줄일 수 있다.

런즈 티처스는 학원이 셔틀 여부 등 정보를 편집할 수 있다고 [공식 안내](https://learns.partners/services/promotion)한다. 이는 학원 입력 정보가 존재한다는 근거이며, 개별 표본의 해당 필드를 학원이 직접 작성·검수했다는 보장은 아니다.

## 추가 비교 설계

후속으로 지역·기관 종류를 나눠 표본을 확보한다. 공식 등록 연결/미확인 기관을 함께 포함하고, 런즈 존재 여부 및 셔틀 항목 미표시도 각각 집계한다. 확인할 지표는 다음과 같다.

- 동일 기관으로 연결 가능한 비율. 브랜드 별칭 후보는 확정 일치와 분리.
- 공식 미확인 중 런즈 셔틀 있음 비율. 미등록 판정으로 사용하지 않음.
- 공식 등록 확인 중 런즈 없음 표기 비율. 어느 쪽이 최신인지 독립 확인 전에는 충돌 후보.
- 기존 마스터 밖 체육시설·공부방·신규기관 비중.
- 학원 홈페이지·학원 직접 확인 등 독립 원천으로 재확인한 비율.

운영 데이터에는 `공식 등록 확인`, `외부 서비스 셔틀 표기`, `학원 직접 확인`을 같은 확정값으로 합치지 않고 출처와 확인일을 보존한다. 공식 등록 확인 플래그를 런즈 없음 표기로 자동 취소하지 않는다.

이번 표본 비교와 서비스용 대량 확보·재게시 범위는 구분한다. [현재 공개 이용약관](https://learns.academy/documents/terms-of-service) 제10조에는 무단 복사·가공·게시와 회사가 동의하지 않는 영리 목적 이용 등에 관한 제한이 있다. 서비스용으로 지속 확보하려면 제공·이용 조건을 별도로 확인하고 제휴/허락 경로를 검토하는 것이 적절하다. 약관에 별도 데이터 API 제공이 명시돼 있다고 확인한 것은 아니다.
